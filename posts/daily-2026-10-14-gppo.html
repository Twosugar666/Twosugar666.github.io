一线追踪｜GPPO：把 PPO / DAPO / DPPO / RIPO 放进同一张「Divergence × Estimator」表——clip 区间其实是 f-散度的 sublevel set，KL × Atomic 比 GRPO 数学均分高 49.8%

2026-10-14 · 收藏夹：RL · 一线追踪
论文：Zhicheng Cai、Xinyuan Guo、Hanlin Wu、Weinan Dai、Yuyan Zhou、Wei-Ying Ma、Ya-Qin Zhang、Hao Zhou（清华 AIR；SIA-Lab of Tsinghua AIR and ByteDance Seed） · Generalized Proximal Policy Optimization: Unifying LLM RL Algorithms from the Perspective of Divergence · arXiv:2610.13015（cs.LG，v1，2026-10-09 提交）。 文中实验数字均为论文自报（Qwen3-8B-Base、veRL、8×H20）；「不同 µ 下的实际 clip 区间」一表是本文按论文公式自行计算。 交叉： PPO、 TRPO、 KL 散度、 DAPO、 GRPO、 GSPO、 Softmax / Entropy。

背景与动机

过去一年 LLM RL 的「PPO 变体」几乎都在改同一个地方：clip。DAPO 把上界放宽到 1+ε_high（Clip-Higher），DPPO 把约束从比率换成概率差 |π−µ|≤δ，RIPO 让 clip 宽度随 µ(a|s) 变化，GSPO / GMPO 把 clip 的单位从 token 换成整条序列……每个都有一段经验动机，但彼此怎么关联、为什么有效，一直缺一个统一说法。

GPPO 给的说法很干净：PPO-Clip 本质是在约束一个单样本 Monte Carlo 估计的 TV 散度。因为 D_TV(π‖µ)=½·E_µ|r−1|，所以 |r−1| 就是 TV 的单样本估计，clip 到 [1−ε,1+ε] 等于要求这个估计 ≤ ε。一旦这样看，PPO 的设计就只剩两个自由度——约束哪个散度 f，以及用什么估计器 T 去估它。论文把四种 f（TV / Pearson χ² / Hellinger / KL）和三种 T（MC / Atomic / Binary）摆成 4×3 的表，发现 GRPO、DAPO、DPPO、RIPO 恰好各占一格。

站内 TRPO 推过 Kakade–Langford / Schulman 的单调改进下界，PPO 讲过 clip 如何「近似」信赖域。这篇正好补上那块缺口：把「近似」写成一个具体的散度与估计器选择。

机制拆解

① 理论底座：任意 f-散度都能接上 TRPO 的单调改进下界

# Theorem 1（Schulman 2015，TV 版）
η(π) − η(µ) ≥ 1/(1−γ) · L_µ(π) − 4ξγ/(1−γ)² · D_TV^max(π‖µ)²
L_µ(π) = E_{s∼ρ_µ, a∼µ}[ r(s,a) · A_µ(s,a) ],   r = π(a|s)/µ(a|s)

# 关键一步：Vajda 紧下界（Theorem 2）
D_f(P‖Q) ≥ L_f(V) := inf_{β∈[0,1−V]}  β·f(1+V/β) + (1−β)·f(1−V/(1−β)),   V = D_TV(P‖Q)
# 证明思路：按 Hahn 分解把样本空间压成 {A, Aᶜ} 两点，Jensen / 数据处理不等式，
#           二点分布可取到下界，所以是紧的

# 取最优二次常数
C_f^Vajda := inf_{0<V≤1} L_f(V)/V²     ⇒   D_TV² ≤ D_f / C_f^Vajda

# Theorem 3：广义 f-散度信赖域
η(π) − η(µ) ≥ 1/(1−γ)·L_µ(π) − 4ξγ / (C_f^Vajda·(1−γ)²) · D_f^max(π‖µ)
# 只要 C_f^Vajda > 0，约束任何 f-散度到足够小的 level set 都保证单调改进
# 附录还给出局部系数 C_f^local = 2f''(1) ≥ C_f^Vajda

这一步本身不新（Pinsker 就是 KL 的特例：D_TV² ≤ ½·D_KL），价值在于把它推广到一族散度，从而允许你按「想要什么样的阻力曲线」挑 f，而不丢理论保证。

② 几何：不同 f 在 r≈1 附近一样，在 r 远离 1 时才分家

对光滑 f 在 r=1 做 Taylor 展开，一阶项因 E_µ[r−1]=0 消失，得到 D_f ≈ f''(1)/2 · E_µ[(r−1)²]——所有 f''(1)>0 的散度局部都是同一个 Fisher–Rao 几何，只差缩放。区别全在有限位移区：

ff(r)f''(r)形状（论文 §3.2）对 clip 的含义
TV½|r−1|0（r≠1）多面体、零曲率、对称阻力与偏移大小无关，固定阈值硬切——PPO-Clip
Pearson χ²(r−1)²2椭球（Mahalanobis）偏移越大阻力越大，但仍对称
KL−log r1/r²非对称、对数扭曲r→0（压低概率）越来越贵，r 变大边际阻力递减 ⇒ 利于把低概率 token 拉起来
Hellinger(√r−1)²1/(2r^{3/2})平方根嵌入下的球面同样向 r→0 方向更硬，比 KL 温和

注意记号：论文约定 D_f(π‖µ)=E_{a∼µ}[f(r)]，所以 f=−log r 对应的是 KL(µ‖π)。另外严格说 −log r 在 r>1 时为负、sublevel set 没有上界；论文在复现 DAPO 时实际使用的是对称区间 −δ≤log r≤δ（即 |log r|≤δ），下文计算沿用这个处理。

③ 估计器拓扑：MC / Atomic / Binary

# 统一形式（式 10–11）：clip 区间 = 估计器的 δ-sublevel set
R̂_f(δ) = { r > 0 : D̂_f(r) ≤ δ }
J_GPPO = E[ min( r·Â,  clip_{R̂_f(δ)}(r)·Â ) ]

MC     : D̂ = f(r)                                   # 只看采到的 token 的比率
Atomic : D̂ = µ(a|s)·f(r)                            # 按旧策略概率加权的「原子贡献」
Binary : D̂ = µ·f(r) + (1−µ)·f( (1−µ·r)/(1−µ) )      # 采到的 token vs 其余全部（二点分布）

# 附录 B：二阶矩 v_Atom(a) = µ(a|s)² · v_MC(a)   → 低概率 token 的长尾被压掉
# 论文还试过 Top-K 估计：O(K) 显存、方差大、δ 难调，放弃

一个容易被忽略的事实：Atomic 不是 D_f 的无偏估计（E_µ[µ·f(r)] = Σµ²f ≠ Σµf），论文称它为「probability-aware」的约束而非更准的点估计，附录给的也是二阶矩对比。理解它最直接的方式是把 sublevel set 解出来——Atomic / Binary 本质上都是「clip 宽度随 µ(a|s) 变化」。

④ 已有方法各占一格

方法(f, T)sublevel set 解出来的 clip 区间
PPO / GRPO(TV, MC)[1−ε, 1+ε]

DAPO(KL, MC)[e^{−δ}, e^{δ}]；δ=0.23 ⇒ [0.80, 1.26]，与 DAPO 的 ε_low=0.2 / ε_high=0.28 近似对应
DPPO(TV, Binary)|π−µ| ≤ δ ⇔ [1−δ/µ, 1+δ/µ]

这张表最有用的地方是把 DAPO 的「上界比下界宽」解释成 KL 几何的自然产物，而不是拍脑袋；同时它也说明 DPPO 与 RIPO 本质上都在做「µ 越小 clip 越宽」，只是放宽的速率不同（1/µ vs 1/√µ）。

⑤ 实际 clip 区间长什么样（自算）

论文的标定方式：固定收缩侧下界 r_min=0.8，令 δ=f(0.8)，得 δ_TV=0.2、δ_χ²=0.04、δ_H≈0.011、δ_KL≈0.223；Atomic / Binary 复用同一个 δ。按这个 δ 解 sublevel set（TV 用 |r−1|，KL 用 |log r|，与论文数值一致）：

fMC（与 µ 无关）Atomic µ=0.5Atomic µ=0.1Atomic µ=0.01Binary µ=0.1Binary µ=0.01
TV[0.80, 1.20][0.60, 1.40][0, 3.0][0, 21][0, 2.0][0, 11]
χ²[0.80, 1.20][0.72, 1.28][0.37, 1.63][0, 3.0][0.40, 1.60][0, 2.99]
Hellinger[0.80, 1.22][0.72, 1.32][0.44, 1.78][0, 4.23][0.46, 1.72][0, 4.18]
KL[0.80, 1.25][0.64, 1.56][0.11, 9.31][0, ≈e^{22}][0.23, 2.30][0, 18.6]

读法：µ 接近 1 时三种估计器差不多；µ 一小，Atomic 迅速放开——KL × Atomic 在 µ=0.01 的 token 上基本等于不 clip，此时真正起作用的是论文统一使用的 dual-clip（比率下限 0.5、上限 10）。所以「最佳配方」的实际行为可以概括为：高概率 token 按 KL 几何温和 clip，低概率 token 几乎放任，再用一个粗的全局比率护栏兜底。这与 DAPO Clip-Higher「给低概率 token 涨价空间以防熵塌」的动机一脉相承，只是放宽程度更激进、且两侧都放。

实验要点（均为论文自报）

  • 设置：Qwen3-8B-Base；数学用 DAPO-Math-17k，代码用 Eurus-Code-25k；group size 8、最大响应 20k token；每轮 1024 条 rollout、train batch 128、更新 8 次、mini-batch 16；0/1 奖励；去掉 KL 惩罚；token-mean 聚合；AdamW 常数 lr 1e-6；数学 400 步、代码 600 步；veRL、8×H20；avg@8。
  • 数学（AIME24 / AIME25 / BRUMO25 / SMT25 平均）：GRPO（TV-MC）27.7；DAPO（KL-MC）34.6；DPPO（TV-Binary）39.0；RIPO（χ²-Atomic）40.5；KL-Atomic 41.5（+49.8%）。GSPO / GMPO 35.1，SAPO 35.0，CISPO 30.5，Clip-Cov 31.5。
  • 代码（Codeforces / CodeContests / TACO / APPS 平均）：GRPO 52.4；KL-Atomic 59.7（+13.9%），Atomic 在代码表每一列都排第一。
  • 估计器比散度更关键：四种散度上平均，Binary 相对 MC 提升 21.3%（数学）/ 3.2%（代码），Atomic 为 28.3% / 7.7%。训练曲线里 MC 的熵很快塌到接近 0、分数早早平台，Atomic / Binary 熵维持在中等水平且持续上涨。
  • 几何受估计器「过滤」：MC 下 KL 比 TV 高 24.9% / 3.6%；但 Binary 下数学上 TV 反而最强（39.0 vs KL 37.2）。论文的解释是 TV-Binary 直接约束绝对概率质量变化，而曲面散度会把同一 δ 变成对稀有 token 更紧的比率惩罚。
  • 标定巧合：TV-MC 与 χ²-MC 结果完全相同（都是 27.7 / 52.4），因为按 r_min=0.8 标定后两者的 MC 区间都是 [0.8, 1.2]——这本身就是一个「区间相同则算法相同」的好例子。

怎么看这篇

值得拿走的：一个统一坐标系。以后看到新的「PPO 变体」，第一件事可以是把它的 clip 规则写成 {r : D̂(r) ≤ δ}，看它落在哪一格、相对 µ 的放宽速率是多少。站内 KL 散度 讲过 k1/k2/k3 三种单样本 KL 估计；GPPO 的 Atomic / Binary 是在「约束」而非「惩罚」这一侧做同类思考。

需要打折的：(1) 单模型（Qwen3-8B-Base）、单次训练、avg@8，没有多 seed 方差；(2) 所有方法共用 r_min=0.8 的标定，等于把每种散度锁在同一收缩下界，DAPO / RIPO 等并未用各自原论文调过的超参；(3) 低 µ 下 Atomic 的区间几乎无界，真实约束由 dual-clip 0.5 / 10 承担，消融里没有单独拆 dual-clip 的贡献；(4) Theorem 3 的单调改进保证针对 D_f^max（逐状态最大），实际实现是逐 token clip，二者之间的距离与 PPO 原本的「近似信赖域」同样存在。

实践建议

  • 先把你的 clip 写成 sublevel set。 若你在用 DAPO 的非对称 clip，可以直接视为 KL-MC；想试 GPPO，最小改动是把 clip 上下界改成 µ 的函数（Atomic：解 µ·f(r)=δ），µ 就是 rollout 时记录的旧策略 token 概率，几乎零额外开销。
  • 一定保留全局比率护栏。 KL-Atomic 在稀有 token 上近乎不 clip，没有 dual-clip（论文 0.5 / 10）时 off-policy 程度高的 mini-batch 可能放大梯度；多次更新（论文每轮 8 次）时尤其要看 grad norm。
  • 盯熵曲线比盯 reward 更早发现问题。 论文最一致的观察是 MC 系列熵快速塌缩；换估计器后若熵反而爆涨，说明低 µ 放得太开，可以把 δ 调小或换 χ² 这类放宽更慢（1/√µ）的组合。
  • 与训推失配一起考虑。 µ 若来自推理引擎（vLLM / SGLang）的 logprob，而 π 来自训练框架，低概率 token 的比率本就噪声大；Atomic 放宽低 µ 的 clip 会让这部分噪声更容易进梯度，配合 TIS / MIS 一类截断修正更稳。
  • MoE 场景另算。 论文只做 dense 8B。MoE 上 token 级比率还受路由变化影响（参见站内 GSPO 与 T1 的 R3 routing replay），放宽 clip 前先确认路由一致性。

思考题

1. 为什么说 PPO-Clip 是在约束「单样本 MC 估计的 TV 散度」？这个视角下它的两个缺陷分别是什么？

D_TV(π‖µ)=½·E_{a∼µ}|r−1|，所以 |r−1| 是 TV 的单样本无偏估计（差常数），clip 到 [1−ε,1+ε] 就是要求该估计 ≤ε。缺陷一是几何：TV 生成函数零曲率、对称，阻力与偏移大小无关、上下对等；缺陷二是估计：只看采到的那个 token 的比率，约束对采样噪声敏感，也不区分高概率与低概率 token。

2. 所有 f''(1)>0 的 f-散度在 r≈1 处等价，那为什么换 f 还会改变训练结果？

局部等价只在 r→1 的二阶近似下成立；clip 恰恰发生在有限位移区（r≈0.8 或 1.25 及以外），这里高阶项与非对称项决定区间形状。比如 KL 在 r→0 一侧更硬、r 增大一侧更软，导致上界比下界宽；再叠加 Atomic 的 1/µ 放宽，差异在稀有 token 上会被成倍放大。

3. Atomic 估计 µ·f(r) 的期望是 Σµ²f，不等于 D_f。为什么它仍然有效？该怎样理解它？

它不是在追求无偏点估计，而是把约束从「这个 token 的比率偏了多少」改成「这个 token 对整体散度贡献了多少」。低概率 token 即使比率偏离很大，对分布级散度的贡献也小，因此不该被提前 clip。解出 sublevel set 后，它等价于 clip 宽度随 1/µ 放宽；附录的二阶矩分析（v_Atom=µ²·v_MC）说明它压掉了稀有 token 的长尾方差。

4. 按论文标定 δ_TV=0.2，请推出 TV-Binary 的区间，并说明它为什么与 DPPO 一致。

以 f=|r−1| 为例，Binary 估计为 µ|r−1| + (1−µ)|(1−µr)/(1−µ) − 1| = µ|r−1| + µ|r−1| = 2µ|r−1|，令其 ≤δ 得 |r−1| ≤ δ/(2µ)；若按论文 ½|r−1| 的 TV 定义则得 |r−1|≤δ/µ，即 |π−µ| = µ|r−1| ≤ δ，正是 DPPO 的约束。两种写法只差常数缩放，本质都是约束绝对概率质量变化。

5. （开放题）把 GPPO 搬到多轮 Agent RL（工具调用、长 observation、token 数极不均衡）时，估计器的选择会有什么新问题？

可讨论方向：(a) Agent 轨迹里大量格式 / 工具名 token 的 µ 接近 1，Atomic 与 MC 差别很小，真正受影响的是推理中的分叉 token，收益可能集中在少数位置；(b) 环境返回的 token 不参与损失，但会改变后续 token 的 µ 分布；(c) 多轮下 off-policy 更重（异步 rollout、partial rollout），低 µ 放宽 clip 叠加 staleness 可能放大方差，需要配合序列级（GSPO 式）或轮次级的比率护栏；(d) 可以考虑按轮次或按 token 类型选择不同的 (f, T)。
