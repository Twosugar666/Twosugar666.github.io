学习笔记｜DAPO：给 GRPO 补上的四个训练细节（Clip-Higher / Dynamic Sampling / Token-level Loss / Overlong）

2026-09-04 · 收藏夹：算法 / RL · 学习笔记
主来源：Yu et al. DAPO: An Open-Source LLM Reinforcement Learning System at Scale， arXiv:2503.14476。 可参考 diffio GRPO/DAPO 笔记 交叉核对，但数字以论文为准并标自报。 交叉： GRPO、 PPO、 REINFORCE、 GSPO、 GAE。

背景与动机

长 Chain-of-Thought + rule-based ±1 奖励 + 多样本组相对，是当前数学推理 RL 的主流配方。 朴素 GRPO 在 Qwen2.5-32B 上作者自报 AIME 2024 avg@32 只有 30，远低于 DeepSeek-R1-Zero-Qwen-32B 自报的 47。 社区复现 R1 式结果时反复撞上熵塌缩、零优势 batch、长度偏置、截断噪声——说明「算法名」之外，还有一堆训练细节没写进短报告。

DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）把四招钉死并开源（verl + 数据）： Clip-Higher、Dynamic Sampling、Token-level Policy Gradient Loss、Overlong Filtering + Soft Overlong Punishment。 累计做到自报 50，且步数约为 R1-Zero-Qwen-32B 的一半。

一句话：DAPO = 非对称 clip（ε_low=0.2 / ε_high=0.28）+ 滤零方差组 + 按 token 归一损失 + overlong 过滤/软惩罚；在 GRPO 骨架上把长 CoT RL 训稳训满。

机制拆解

① GRPO 回顾：组相对，无 critic——也会「全零优势」

# 同 prompt 采 G 条 completion，奖励 r_i（常为 rule ±1）
A_i = (r_i − mean(r)) / std(r)     # 组内标准化

# 若组内奖励全相同（全对或全错）→ std≈0 或 A_i 全 0
# → 该组对 policy gradient 无贡献（梯度饥饿）

# 无 critic：省掉 V，但把「可分信号」完全押在组内奖励方差上
# 骨架仍是 REINFORCE / PPO 式 score-function，见站内 REINFORCE / PPO 课

DAPO 的场景差异：长 CoT、多 update / sample reuse 让 clip 真正起作用；同时作者配方删 KL（相对经典 PPO/部分 GRPO 实现），更依赖 clip 与采样质量控更新。

② Clip-Higher：非对称上下界，给 exploration token 留抬头空间

# 经典 PPO/GRPO 常对称 clip：ratio ∈ [1−ε, 1+ε]
# 长 CoT 里：提高低概率「探索 token」的概率时，ratio 上冲易被 1+ε 掐死
# → 策略熵塌缩，多样性死亡

# Clip-Higher（解耦上下界）
ε_low  = 0.2     # 向下（抑制过高概率动作）仍较紧
ε_high = 0.28    # 向上放宽，允许探索 token 抬概率
# clip(ratio, 1−ε_low, 1+ε_high)

「Decoupled Clip」名字里的解耦：上下界不再绑死同一 ε。工程直觉——对称 clip 在「需要抬尾部概率」时不友好；略放宽上界，换熵与探索，是长 CoT 上的第一剂。

③ Dynamic Sampling：过滤零方差组，直到 batch 满

# 问题：全对 / 全错组 → advantage 全 0 → 有效 batch 变瘦 → 不稳定
# Dynamic Sampling：
#   持续采样，丢弃「组内奖励无方差」的 prompt 组
#   直到有效组数凑满目标 batch

# 代价：采样次数↑；作者观察：收敛时间未必变长——
#   因为每次更新的梯度更「有信号」，无效 step 变少

这与「加大 G」不同：G 再大，若题太易/太难仍可能整组同奖励。动态过滤直接对准梯度饥饿。消融里它贡献了从 42→50 的最大单跳（累计设定下）。

④ Token-level Loss：按组内总 token 归一，别让长答稀释每 token 梯度

# 样本级平均（示意问题）
#   每条 completion 先在内部对 token 平均，再对 G 条平均
#   → 长答每个 token 的有效权重被长度稀释
#   → 模型可能偏好短/长的有偏模式，长 CoT 不稳定

# Token-level Policy Gradient Loss：
#   分子：所有样本、所有 token 的 clip-surrogate 之和
#   分母：组内（或 batch 内）总 token 数
# → 每个 token 梯度尺度与序列长度解耦得更干净

作者自报：token-level 单项涨点不大（41→42），但训练更稳、长度增长更健康。长 CoT RL 里「稳」往往比「多 1 分」更值钱。 对照 GSPO：GSPO 强调序列级 IS；DAPO 这里强调损失归一粒度——问题不同层，都可同时存在。

⑤ Overlong：过滤 + 软惩罚，压截断噪声

# Overlong Filtering：
#   超长截断样本奖励噪声大（没答完却被打 ±1）→ 训练中过滤 / 不计入

# Soft Overlong Punishment：
#   软帽 L_soft 之后开始线性惩罚，直到硬帽 L_hard
#   未到软帽：不罚；超过硬帽：最大惩罚 / 截断逻辑按实现
# → 比「一超长就 -1」更平滑，减少奖励悬崖

长生成是推理 RL 的一等公民：截断不是边界情况，而是日常。Overlong 两招把「长度噪声」从 outcome 信号里剥出去，否则 GRPO 组相对会学到「别写太长」或「赌截断」的歪策略。

⑥ 累计消融（论文自报，务必读作累计而非独立）

配置（Qwen2.5-32B，AIME 2024 avg@32）自报分数
Naive GRPO30
+ Overlong Filtering36
+ Clip-Higher38
+ Soft Overlong Punishment41
+ Token-level Loss42
+ Dynamic Sampling（= 完整 DAPO）50
对照：R1-Zero-Qwen-32B47（约 2× 步数）

读消融三戒：① 这是累计加技，不是各自从 30 起的独立贡献；② 单 seed / 单 benchmark（AIME24 avg@32）叙事；③ 「半步数超 47」是论文效率主张，复现时对齐数据、长度帽与评测协议。 最大跳点来自 Dynamic Sampling（42→50），但前面四招把系统推到「梯度质量成为瓶颈」的位置——缺前序时只开动态采样，未必复制同幅增益。

实践建议

  • 先画组内奖励方差曲线。 零方差组占比高 → 优先 Dynamic Sampling / 调难度，再谈学习率。
  • 对称 clip 熵塌就试 Clip-Higher。 记录 ε_high 与策略熵；上界不是越大越好，0.28 是论文锚点。
  • 长 CoT 默认改 token-level 归一。 对照样本级平均跑一次长度直方图与梯度范数，再决定是否回退。
  • Overlong 软硬帽写进奖励合同。 过滤与软惩罚服务不同噪声；只罚不滤或只滤不罚都要单独消融。
  • 删 KL 不是免费午餐。 DAPO 配方依赖 clip+采样质量；若 off-policy 很激进，先确认 reuse 次数与 clip 是否匹配。
  • 与站内笔记串读。 PPO 讲 clip 起源，GRPO 讲组相对，REINFORCE 讲骨架，GSPO 讲序列 IS，GAE 讲有 V 时的优势；DAPO 是「无 critic 长 CoT」工程四件套。

思考题

  1. 为什么同组奖励全相同会让 GRPO「没梯度」？
    参考答案 A_i=(r_i−mean)/std。全同奖励时偏差为 0（或 std 数值不稳定），优势信号消失，clip-surrogate 对参数的有效梯度接近 0。Dynamic Sampling 通过丢掉这类组、凑满有方差 batch 来避免梯度饥饿。
  2. Clip-Higher 为何能缓解熵塌缩？对称 clip 卡在哪？
    参考答案 抬升低概率探索 token 时 importance ratio 常 >1，对称上界 1+ε 过早截断正优势更新，探索抬不起来，熵下降。ε_high>ε_low 给上冲留空间，同时向下仍紧，抑制过激放大。
  3. Token-level Loss 与「按样本平均再平均」差在什么归纳偏置？
    参考答案 样本级平均让长序列每个 token 权重变小，短序列相对更「大声」，长度与梯度耦合。按总 token 归一后，每个 token 贡献更均匀，长 CoT 的逐步决策不会被长度系统性地稀释。
  4. 为何说累计消融不能解读为「Dynamic Sampling 单独 +8」？
    参考答案 表中每一行叠在上一行之上。42→50 的 +8 以 Overlong/Clip/Token-level 已就位为前提；没有前序时，零方差过滤的对象分布与梯度景观不同，不能把 +8 当成该技的独立 ATE。
  5. DAPO 与 GSPO、PPO 如何摆在同一工具箱里？
    参考答案 PPO：通用 clip +（常有）GAE/V。GRPO：组相对无 critic。DAPO：在 GRPO 长 CoT 场景补齐 clip 非对称、采样过滤、token 归一、overlong 塑形。GSPO：序列级 IS，尤其 MoE。选型上可组合：用 DAPO 稳 outcome RL，用 GSPO 稳 MoE 路由下的 IS；有逐步价值时再引入 GAE。
