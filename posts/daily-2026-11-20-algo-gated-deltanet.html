学习笔记｜Gated DeltaNet：把 Mamba2 的衰减门与 DeltaNet 的精确覆写合成一个 gated delta rule，用 WY 表示做分块并行——1.3B/100B token 下 WikiText-103 PPL 16.42 vs Mamba2 16.56，S-NIAH-2 4K 检索 92.2 vs Mamba2 56.2

2026-11-20 · 收藏夹：算法 / Infra · 学习笔记
来源：Songlin Yang（MIT CSAIL，工作完成于 NVIDIA 实习）、Jan Kautz（NVIDIA）、Ali Hatamizadeh（NVIDIA）· Gated Delta Networks: Improving Mamba2 with Delta Rule（arXiv:2412.06464，cs.CL / cs.LG，ICLR 2025 camera ready，v1 2024-12-09 / v3 2025-03-06）。 数字均为论文自报：主实验为 1.3B 参数、100B FineWeb-Edu token、4K 训练长度（混合模型 SWA 窗口 2K），同条件对比；S-NIAH 为 1.3B 模型零样本。「box 小验证」一节为本文用纯 Python 实现 gated delta 更新式与记忆碰撞玩具的实算。 交叉： MQA / GQA / MLA、 FlashAttention、 Attention 基础、 序列并行、 RoPE。

背景与动机

Self-attention 的代价随序列长度平方增长。线性 Transformer 把 softmax 注意力换成核化的点积线性注意力，等价于一个矩阵值状态的线性 RNN，推理时每步 O(d²) 而不是 O(L·d)，显存也不随序列长度堆 KV cache。本文之前在 MQA / GQA / MLA 里讲过另一条"压 KV"的路；线性注意力走的是"干脆不做全对比"的另一极。

但线性 Transformer 有个根本短板：它实现的是一种外积形式的 key-value 联想记忆，能存的近似正交 key-value 对数被模型维度 d 限住；序列一长，"记忆碰撞"不可避免，精确检索掉队。近两年的两条改进路线各自补了一块：

  • 门控（gating），代表 Mamba2 / GLA / RetNet：每步用数据相关的标量衰减 α_t ∈ (0,1) 把整个状态乘小一点，S_t = α_t S_{t−1} + v_t k_tᵀ。好处是能"整体遗忘"，坏处是要忘一个就全部一起忘——不区分哪些联想重要。
  • delta 更新规则，代表 DeltaNet：不是累加，而是"软替换"旧的 key-value 对——S_t = S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ。好处是精准写入、检索强；坏处是一次只改一个 pair，没法快速清空，遇到上下文切换（旧信息要整体作废）就吃亏，真实任务上表现中等。

Gated DeltaNet 的洞见很干净：这两者是互补的。门控 = 快速擦除（α_t→0 清空记忆），delta = 精准更新（α_t→1 退回纯 delta rule）。把它们合进同一个更新式，就同时拿到"该清就清、该改就改"的能力，且不牺牲硬件效率——这是它能进 ICLR 2025 的核心。

机制拆解

① 三种记忆更新：线性注意力 → Mamba2 → DeltaNet → Gated DeltaNet

模型状态更新记忆语义短板
线性 TransformerS_t = S_{t−1} + v_t k_tᵀ纯累加，无遗忘语言建模远差于 Transformer
Mamba2 / RetNetS_t = α_t S_{t−1} + v_t k_tᵀ标量衰减，整体淡出无法定点遗忘；忘记一个就全忘
DeltaNetS_t = S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ精准覆写匹配 key 的槽无法快速清空；上下文切换吃亏
Gated DeltaNetS_t = S_{t−1}(α_t(I − β_t k_t k_tᵀ)) + β_t v_t k_tᵀα 控制擦除、β 控制覆写门控是标量（比矩阵值衰减表达力弱）
 
gated delta rule (Eq. 10):
  S_t = S_{t−1} · ( α_t (I − β_t k_t k_tᵀ) ) + β_t v_t k_tᵀ
        └ 旧状态 ┘   └─ 衰减 + 沿 k 方向擦除 ─┘   └ 新写入 ┘

  α_t ∈ (0,1) 数据相关的衰减门；β_t ∈ (0,1) 写入强度
  α_t → 0 : 整块记忆快速清空（context switch）
  α_t → 1 : 退化为纯 delta rule，只改匹配 k_t 的那一路
  β_t → 1 : 完全覆写；β_t 小则部分混合

从 SSD（state space duality）的视角，Mamba2 的衰减可以写成并行形式 O = ((QKᵀ) ⊙ Γ) V，其中 Γ_{ij} = γ_i / γ_j（i≥j）、γ_j = ∏_{i≤j} α_i 是累积衰减积。gated delta rule 在这一层加了"沿 k 方向的低秩擦除"，这正是它比纯衰减表达力强的来源。

② 硬件效率：为什么不能逐时间步串行更新

上面的递推式是 O(L) 串行的，在现代 GPU 上慢得不能用。论文沿用 DeltaNet 用 WY 表示（Bischof & Loan 1985）并行化 delta rule 的思路，并把它扩展到带门控的情形：把一段内的多个秩-1 擦除 (I − β_i k_i k_iᵀ) 合并成一个可并行计算的矩阵求逆类结构，从而保留分块并行（chunkwise parallel）训练。三种形态各有用处：

形态计算适用
递推（recurrent）逐步 S_t，O(L) 串行推理（每步 O(d²)，不堆 KV）
并行（parallel）矩阵形式一次算 L×L 掩码，O(L²)短序列训练、理论统一（SSD）
分块并行（chunkwise）切块大小 C，块内并行 + 块间递推，线性时间、rich in matmul训练主力，吃 tensor core

分块形式的核心是：每块的初始状态 S_[t] 来自上一块末态，块内先算 O_[t] = Q_[t] S_[t]ᵀ + (Q_[t]K_[t]ᵀ ⊙ M) V_[t]（局部，全是矩阵乘），再把本块的贡献累进 S_[t+1]。delta 规则下多出来的低秩擦除项用 WY 表示合并，使这一步也能写成 matmul。论文报告的吞吐：在单张 H100 上，Gated DeltaNet 与 DeltaNet 几乎同速，比 Mamba2 略慢约 2–3K tokens/s（因为转移矩阵表达力更强）；混合了 2K 滑窗注意力的 H1 / H2 反而比纯 mixer 更快。

本站之前讲过 FlashAttention 的"用 IO 感知的分块把注意力从显存瓶颈里救出来"，以及 序列并行 的 Ulysses / Ring。Gated DeltaNet 的分块并行是同一类工程哲学：把数学上等价的递推重构为 matmul-heavy 的分块形式，让算法吃到 tensor core——区别是一个在压注意力的 IO，一个在把 RNN 递推"矩阵化"。

⑤ 检索与长上下文：gated delta 的真正主场

线性注意力最弱的是精确检索，论文用 S-NIAH（单 needle in a haystack）直接量这个能力（1.3B 模型，准确率 %）：

Mamba265.4 / 30.456.2 / 17.047.6 / 4.6

最醒目的是 S-NIAH-2（数字 needles）在 4K：DeltaNet 18.6、Mamba2 56.2、Gated DeltaNet 92.2；8K 时各自 14.4 / 17.0 / 29.6——长到一定程度所有线性模型都掉，但 gated delta 掉得最慢。S-NIAH-1 上 DeltaNet 短上下文 99.0 略高，但 Gated DeltaNet 在 8K 有 91.8，而 Mamba2 只剩 30.4——这正是"门控擦除 + 精准覆写"相对"纯衰减"的价值：衰减把 needle 连同上下文一起淡出了。

⑥ box 小验证（纯 Python：更新式等价 + 记忆碰撞）

两个最小验证。第一，验证 gated delta 更新式的两种写法等价（WY 合并的代数基础）：S(α(I−βkkᵀ)) + βvkᵀ 应该逐位等于 αS − αβ(Sk)kᵀ + βvkᵀ。第二，用近平行的两个 key（cos≈0.996）演示"纯衰减会把旧联想泄漏出来，delta 覆写会把它挤掉"： 

max |lhs − rhs| of gated-delta update rewrite = 8.882e-16     # 两种写法逐位一致

k1,k2 近平行 (cos = 0.9959)，先后写入 v1, v2 后读 k1：
  decay-only (α=0.99) : read(k1) -> v1=+0.990, v2=+0.996   # 旧 v1 还在，串味
  gated delta (α=1,β=1): read(k1) -> v1=+0.008, v2=+0.996   # v1 被 v2 覆写

结论：α_t→0 提供"整块清空"（context switch），α_t→1 退回 delta 的"定点覆写"。
这正是 S-NIAH-2 上 gated delta 92.2 远高于 Mamba2 56.2 的微观机制。

实践建议

  • 线性注意力选型先看"检索密度"：语言建模 PPL 上各线性模型差距不大（16.4–16.6），但 S-NIAH 差出几倍。如果下游有大量精确 key-value 召回（长文档问答、代码符号定位），优先带 delta 覆写的变体，而不是纯衰减。
  • 混合架构仍是默认最优：H1/H2 在真实 recall 任务上 39–40，超过纯 Gated DeltaNet 30.6 和 Transformer++ 37.0，且吞吐比纯 mixer 更高。工程上"主体线性状态 + 2K 滑窗注意力"是当下性价比最高的点。
  • 门控是标量，不是万能药：论文明确指出 Mamba2 的 α 是标量（对整个状态统一衰减），gated delta 继承这一点；要表达"不同维度不同衰减"需要矩阵值门控，代价是更复杂的参数化和训练算法。别指望 α 一个标量解决所有遗忘模式。
  • 推理侧的价值最实在：线性 RNN 形式每步 O(d²)、状态大小与序列长无关，长上下文推理不用堆 KV cache——这与本站 KV 分层 讨论的"KV 比 GPU 还慢"问题是两条不同的解法。训练用分块并行，推理用递推，同一套权重两种形态（SSD 对偶）。
  • S-NIAH-3 的 4K 列仍有陷阱：Gated DeltaNet 27.6、Mamba2 只剩 4.6，看着是 gated delta 大胜，但绝对数也不高——uuid 类高精度检索对线性状态依然困难，别用它替换需要逐字精确的注意力层。
  • 读数注意：吞吐的相对结论（比 Mamba2 慢 2–3K tok/s、混合更快）来自单 H100 的 Figure 3，论文正文只给范围描述而非逐模型精确表；引用时说"同量级、略慢"比报一个具体数更稳妥。

思考题

1. 为什么 Mamba2 在 S-NIAH-1 4K 只有 65.4，而 DeltaNet 有 99.0，可到了真实 recall 任务 DeltaNet 反而更差（26.2 vs Mamba2 29.8）？

S-NIAH-1 是 pass-key 检索，key 几乎正交、只需把一个精确 pair 存住——delta 规则的"软替换"正好擅长精准写入，所以 DeltaNet 接近满分；Mamba2 的标量衰减会把 needle 随时间淡出，4K 就掉到 65.4。但真实任务里 key 高度相关、需要同时保持多段信息并灵活清理旧内容：DeltaNet 一次只改一个 pair、缺少快速清空机制，上下文一切换旧记忆还在，综合分就落到 Mamba2 之下。Gated DeltaNet 用 α 补上"快速擦除"，于是两个场景都兼顾：S-NIAH-1 8K 91.4/91.8（不像 Mamba2 崩到 30.4），真实 recall Avg 30.6（所有纯线性模型最高）。

2. "WY 表示把 delta rule 并行化"到底解决了什么问题？如果直接逐步算递推会怎样？

delta 更新 S_t = S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ 表面上是 O(L) 串行：每步都要等上一步的 S。直接用 Python 循环或不能融合的 kernel，GPU 的大量 CUDA core / tensor core 闲着，长序列训练极慢。WY 表示把一段内多个秩-1 修正 (I − β_i k_i k_iᵀ) 累积成一个矩阵（形如 I − W Yᵀ），从而把块内计算写成大矩阵乘，可以一次性在 tensor core 上算完，块间仍递推——这就是 chunkwise parallel：线性时间、matmul-heavy。本文进一步把 α_t 门控塞进这个结构（α_t(I − β_t k_t k_tᵀ)），保持了同样的并行性，所以 gated delta 的吞吐能和 DeltaNet 几乎一样。

3. 为什么说 α_t→0 和 α_t→1 分别对应两种极端记忆操作？用它解释"上下文切换"场景。

更新式 S_t = S_{t−1}(α_t(I − β_t k_t k_tᵀ)) + β_t v_t k_tᵀ 里，α_t 乘在整个旧状态上。α_t→0 时旧状态整体被清零（无论 k_t 是什么），新 pair 写进空记忆——相当于"翻篇"，正好对应文档/对话主题切换时把之前所有联想作废。α_t→1 时第一项变成 S_{t−1}(I − β_t k_t k_tᵀ)，就是纯 delta rule：只沿 k_t 方向擦掉旧的 v、再写入新的，其它联想原样保留——对应同一主题内的定点更新。box 实验里两个近平行 key 就是这两种操作的对照：纯衰减（近似 α 统一偏小但非零）让 v1 泄漏，delta 覆写把 v1 挤掉。

4. 本文与 MQA / GQA / MLA 都在解决"注意力太贵"，两者的根本差别是什么？什么时候选哪条？

MQA/GQA/MLA 属于"保留 softmax 注意力，但压缩 K/V 的表示与头数"——仍是二次复杂度的全对比，只是把每步要从显存读的 KV 变小（MLA 用低秩联合压缩 + 解耦 RoPE），服务侧收益直接、生态兼容好。Gated DeltaNet 属于"换掉 softmax 注意力"，用固定大小的矩阵状态做线性时间的联想召回——推理时完全不堆 KV，长上下文显存恒定，但精确检索弱于全注意力（真实 recall 30.6 vs Transformer++ 37.0）。选型：如果模型已基于 Transformer、要兼容现有推理栈、上下文几万以内，先上 MLA/GQA；如果追求极长上下文的恒定显存和线性推理、能接受混合架构，考虑 Gated DeltaNet + 滑窗注意力（H1/H2），它在真实 recall 上反而更高（40.1）。

5. （开放题）gated delta 的状态是 d_v × d_k 的矩阵，为什么长序列不会 OOM？它的"固定大小"代价是什么？

因为状态 S 的尺寸只由 head 维度 d_v、d_k 决定，与序列长度 L 无关——每步读入新 token 就更新同一个 S，不像自注意力要把所有历史 token 的 K/V 都留着。所以 L 从 4K 涨到 1M，状态显存不变，这是它相对 KV cache 的结构性优势。代价是信息带宽：一个 d×d 的矩阵最多可靠地存约 d 个正交 key-value 对（论文强调的"memory collisions"），超过就碰撞、被覆盖——它牺牲的是"无损保留所有历史 token"的能力，换取固定显存。真实任务因此需要门控（定期清理）和 delta（精准更新）来提高有限状态的利用率；混合架构再用一小窗精确注意力兜住最近的高精度需求。理解这个 trade-off，就知道它不是注意力的"免费替代"，而是另一种资源分配。
