你好，博客！为什么我开始写技术博客

2026-08-13 · Xuanbo Guo

这是这个博客的第一篇文章。站点基于纯 HTML/CSS/JS 构建，托管在 GitHub Pages 上——简单、快速、完全免费。

为什么写博客

读研之后，每天接触的信息密度越来越高：论文、代码、实验、实习项目……很多东西当时觉得「肯定忘不了」， 三个月后回看却只剩模糊的轮廓。写博客对我来说是一种外置记忆，也是一种倒逼自己把知识讲清楚的方式。

会写些什么

  • 🤖 多模态大模型：VLM 架构、训练技巧、评测方法
  • 🧠 Agent 系统：强化学习微调（如 GRPO）、多智能体协作
  • 🎨 神经渲染与 3D 感知：NeRF、可微渲染及其在医学影像中的应用
  • 📓 偶尔的实习随笔与学习笔记

这个站是怎么搭的

没有使用任何静态站点生成器，直接手写 HTML + CSS + 少量 JavaScript， push 到 Twosugar666.github.io 仓库后由 GitHub Pages 自动发布。 支持浅色/深色主题切换，样式全部在一个 CSS 文件里，方便随时调整。

「写作是把网状的思想，用树状的结构，线性地表达出来。」—— 与君共勉。
