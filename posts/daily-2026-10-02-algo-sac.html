学习笔记｜SAC：最大熵 Actor-Critic 如何用温度 α 稳住探索

2026-10-02 · 收藏夹：算法 / RL · 学习笔记
经典：Haarnoja et al. · Soft Actor-Critic（ICML 2018 及后续自动温度 / 离散变体）。 交叉： Actor-Critic、 Softmax / Entropy、 PPO、 KL、 GAE。

背景与动机

连续控制里，朴素 Actor-Critic 常在「探索不够」与「Q 过估计把策略拧死」之间反复横跳。 Soft Actor-Critic（SAC）把目标改成最大熵：既要高回报，也要策略在状态上保持足够随机。 温度 α 把「回报」和「熵」拧在同一标尺上——不是外挂一个越来越小的 ε-greedy，而是让最优策略本身偏好高熵。

站内已有 Actor-Critic 骨架、 Softmax / Entropy 的温度直觉、 PPO 的 on-policy 裁剪叙事。 本文聚焦 SAC 的 off-policy 最大熵机制：双 Q、reparameterization、自动 α，以及和「熵 bonus / KL 惩罚」的差别——不复述教科书定义堆砌。

一句话：J(π) = E[Σ_t γ^t (r_t + α H(π(·|s_t)))]； 双 Q 取 min 抑过估计；重参数化稳策略梯度；α 可对 target entropy 自动调节。

机制拆解

① 最大熵目标：回报 + 温度 × 熵

# Soft 目标（无限期折扣形式，概念写法）
J(π) = E_{τ~π} [ Σ_{t=0}^{∞} γ^t ( r(s_t, a_t) + α H(π(·|s_t)) ) ]

# Soft Bellman backup（动作价值）
Q(s,a) ← r + γ E_{s'} [ V(s') ]
V(s)   = E_{a~π} [ Q(s,a) − α log π(a|s) ]   # soft value

α → 0 时退回普通期望回报最大化；α 越大，越偏向「在差不多好的动作上摊平概率」。 这与 Softmax 温度同族：温度是探索–利用的连续旋钮，但 SAC 把旋钮嵌进最优性条件，而不是只在采样时加噪。

② 与 PPO / 普通 AC / 「熵 bonus」对照

SACPPO（典型）AC + 熵 bonus
数据 off-policy replay on-policy 批次 两者皆可，常见 on-policy
探索 目标内最大熵（α） 采样随机性 + 可选熵系数 损失里加 β H(π)，β 常手调衰减
价值 soft Q / soft V 标准 V；advantage 常用 GAE 标准 Q/V
策略更新 最小化 α log π − Q（重参数化） 裁剪的重要性比 × advantage 策略梯度 ± 熵项
与 KL 不靠显式对旧策略 KL 裁剪 比率裁剪 ≈ 信任域直觉 无内建；可另加 KL

「AC + 熵 bonus」看起来像 SAC，但 soft Bellman 与策略目标是否同一套 soft 最优性，决定了 α 能不能被解释成温度。 只在损失末尾加 βH、价值仍用硬 max/期望，探索激励与 backup 不一致时，β 往往只能当启发式。 相对 KL 约束：PPO/TRPO 限制「别离旧策略太远」；SAC 的 α 限制的是「当前策略要有多随机」——一个管更新步长几何，一个管最优策略形状。

③ 双 Q、重参数化、自动温度

组件做什么实现注意
Twin Q（取 min） 两套 Q_θ1, Q_θ2，backup / 策略用 min(Q1,Q2) 抑制过估计；别只训练一个又在目标里假装 twin
Reparameterization a = f_φ(ε; s)，ε~噪声，梯度穿过 f 连续高斯策略标配；比 score-function 方差更低
自动 α 约束 E[−log π] ≈ H_target，对 log α 做对偶上升 H_target 常取 −dim(A)（每维约 e 纳特的启发式）；环境尺度变了要重校
Target soft V / Q Polyak 平均目标网 与双 Q、replay 一起，构成稳定 off-policy 三角 
# 策略损失（概念）
L_π(φ) = E_{s,ε} [ α log π_φ(a|s) − min_i Q_θi(s, a) ]
         where a = f_φ(ε; s)

# 温度（自动）：朝 target entropy 对齐
L(α) = E_{a~π} [ −α log π(a|s) − α H_target ]   # 对 log α 优化更稳

④ 离散动作与常见坑

  • Discrete SAC：动作可枚举时，Q(s,·) 与 π(·|s) 可在类别维上精确求和，不必重参数化高斯；温度与 soft value 形式保留。一笔带过：实现差异主要在「期望怎么算」，不是换掉最大熵目标。
  • Target entropy 过大：策略过平，任务回报上不去；过小则塌成近乎确定性，失去 SAC 相对 DDPG 系的探索优势。
  • 只用一个 Q 或取 max：过估计回来，策略冲向虚高动作。
  • 把 α 当学习率调：α 改的是最优策略的熵，不是 SGD 步长；与 actor/critic lr 混拧会很难复现。
  • 和 GAE 混用时分清 on/off-policy：SAC 主路径是 replay + soft Q；GAE 是 on-policy advantage 工具（见 GAE），不是 SAC 的必选配件。

实践建议

  • 连续控制默认：twin Q + 重参数化 + 自动 α。 手调固定 α 只在动作维度极低、已有良好量级直觉时省事。
  • 先定 H_target，再谈 α 初值。 常见 −dim(A)；若早期熵远低于目标，检查 log_std 上下限是否被夹死。
  • 回报尺度变化时重做温度。 换 reward 归一化等于换「焦耳」定义，旧 α / H_target 可能全部失效。
  • 监控 Q1−Q2 间隙与策略熵。 间隙持续拉大 → 过估计风险；熵塌缩 → 探索不足或 α 过小。
  • 需要信任域时显式加 KL，而不是幻想 α 能替代 PPO 裁剪。 两者解决的问题不同（见上表）。

思考题

1. α→0 时 SAC 还「软」吗？

目标退回标准期望回报；soft value 中的 −α log π 项消失，行为接近普通 off-policy actor-critic（仍可能保留双 Q 等实现细节）。

2. 为什么策略损失是 α log π − Q，而不是直接最大化 Q？

最大熵最优策略满足 π* ∝ exp(Q/α)；等价地最小化 α log π − Q。只最大化 Q 会推向确定性贪婪，丢掉熵项。

3. 双 Q 取 min 会不会系统性低估？

会有偏保守；换来的是抑制过估计导致的策略崩溃。实践中对连续控制通常净收益为正，但不是理论无偏。

4. 自动温度与 PPO 熵系数退火有何不同？

自动 α 对准设定的 target entropy（对偶）；PPO 的熵系数多是外源日程表。前者目标是「熵水平」，后者常是「逐渐关探索」。

5. 何时更该用 PPO 而不是 SAC？

强 on-policy 约束、离散大动作空间配合大规模 LLM RL、或必须严格信任域时，PPO/GRPO 系更常见；连续控制 + 可大规模 replay 时 SAC 往往更省样本。
