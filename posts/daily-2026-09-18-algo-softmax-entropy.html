学习笔记｜Softmax / Temperature / Entropy：策略分布如何被「温度」拧软，又如何被熵正则稳住

2026-09-18 · 收藏夹：算法 / RL · 学习笔记
经典工具：softmax 策略、温度 τ、策略熵 H(π)、熵 bonus / entropy coef。 交叉： REINFORCE、 PPO、 GRPO、 KL 散度、 Attention、 Gumbel-Softmax。

背景与动机

离散动作（或 LLM token）上的策略几乎总是 π(a|s) = softmax(z / τ)：logits 经温度缩放再归一化成分布。 τ 拧大，分布变「软」，探索面变宽；τ → 0，质量塌到 argmax，变成近乎确定性策略。 训练侧另有一条旋钮：在目标里加熵 bonus（或 entropy coef），直接奖励「别太尖」——与采样温度相关但不是同一个旋钮。

本篇把三条线串起来：softmax / τ 如何塑形；∇logπ = φ − E_π[φ] 为何对策略梯度友好；熵正则如何出现在 PPO / GRPO；以及采样温度 vs 训练温度、词表熵陷阱等实践坑。 Attention 里的 softmax(QKᵀ/√d) 是同一归一化家族（见 Attention），但此处焦点是策略分布。

一句话：π = softmax(z/τ) 用温度拧软探索；∇logπ 对 logits 的梯度是「特征减期望」；熵 bonus 在训练目标里显式稳住分布宽度——PPO/GRPO 的 entropy coef 管训练，采样 τ 管推理，二者勿混用同一数字叙事。

机制拆解

① Softmax 与温度 τ

# 离散策略（动作或 token）
π(a|s) = exp(z_a / τ) / Σ_b exp(z_b / τ)

# τ > 1  → 分布更平，探索更强
# τ = 1  → 常用默认
# 0 < τ < 1 → 更尖，偏剥削
# τ → 0  → 近 one-hot（argmax）

# 数值稳定：先减 max(z)，再除 τ
z' = (z − max(z)) / τ
π  = exp(z') / Σ exp(z')
旋钮作用面典型用途
采样温度 τ_sample 推理 / rollout 时从 π 取样 解码多样性、探索
训练温度 τ_train 算 logπ / 损失时用的缩放 与标签平滑、蒸馏、部分 RL 实现相关
Entropy coef c_ent 目标里 + c_ent · H(π) 防过早塌缩；与 τ 互补

Gumbel-Softmax 用另一路温度把离散采样变成可微松弛；本页的 τ 是策略/解码温度，不要和 Concrete 松弛温度混谈成「同一个温度故事」。

② ∇logπ = φ − E_π[φ]

# 设 π(a) ∝ exp(φ_a)，φ 为 logits（或 z/τ）
log π(a) = φ_a − log Σ_b exp(φ_b)

# 对 φ 的梯度（示意）：
# ∂ logπ(a) / ∂φ =  1_a  − π
# 即：选中动作的方向推高，同时按 π 加权压低全体 —— 「特征减期望」

# 策略梯度（REINFORCE 骨架）：
# ∇_θ J ≈ E[ ∇_θ log π_θ(a|s) · G ]
# 见 daily-2026-09-03-algo-reinforce.html

「减期望」保证：在同一状态下对所有动作按 π 平均，∇logπ 的期望为 0——这是似然比梯度能配 baseline / advantage 的几何前提之一。 接到 PPO / GRPO 时，仍是对 logπ（或 ratio）加权，熵项则另算 H(π)= −Σ π logπ。

③ 熵 bonus：稳住分布宽度

形式写法（示意）直觉
最大化熵 maximize E[R] + c_ent · H(π(·|s)) 同样回报下偏好更不确定的策略
PPO 常见 L = L_clip − c_vf · L_value + c_ent · H entropy coef 防过早确定性塌缩
GRPO / LLM RL clipped surrogate ± KL 项，常另加 token 级熵 与 KL 分工：KL 锚参考分布，熵管自身尖锐度
Soft Actor-Critic 族 温度 α 乘熵（连续控常见） α 可学；离散 LLM 栈里更常见固定 c_ent 
# 熵定义（离散）
H(π(·|s)) = − Σ_a π(a|s) log π(a|s)

# 与温度的粗糙对照（固定 logits 时）：
# τ ↑ ⇒ H ↑（更平）；τ ↓ ⇒ H ↓（更尖）
# 但：训练时改 c_ent 改的是目标，不一定等于改采样 τ
# 推理时只改 τ_sample，也不自动等于训练见过的熵水平

④ 采样温度 vs 训练温度；词表熵陷阱

坑机制常见处理
采样 τ ≠ 训练分布 用 τ=1.2 采样、用 τ=1.0 的 logπ 算梯度 → 分布不一致 rollout 与 logprob 记账温度对齐；或显式 importance 修正
词表熵陷阱 |V| 很大时，均匀分布熵 = log|V| 巨大；token 平均熵难比跨模型 报「相对均匀的归一熵」或 top-k 质量上的熵；统一分母
熵与 KL 混成一个旋钮 熵管「自己尖不尖」，KL 管「离 ref 远不远」 日志分列 H 与 KL；分开扫 c_ent 与 β
长序列平均熵掩盖塌缩 多数 token 高熵、关键位已 argmax 按位置 / 工具调用位分层监控；看 argmax 率

Attention 的 √d_k 缩放也是在管 softmax 尖锐度（见 Attention）；策略温度是同一数学物件的另一工程表面。RL 日志里若只写「entropy」，务必注明是 token-average H(π)、序列级，还是解码 τ。

实践建议

  • 先对齐采样与记账温度：rollout 用的 τ 与算 ∇logπ 用的 τ 不一致时，先修这个，再谈 entropy coef。
  • c_ent 与 β_KL 分开扫：熵塌缩时先看 H 曲线；离 ref 太远时看 KL。两者同时动只会归因混乱。
  • 词表熵不要跨模型裸比绝对值：至少除以 log|V|，或固定评测词表子集。
  • 推理温度当产品旋钮，训练温度当实验因子：改用户侧 decoding τ 不等于复现训练探索；写报告时分开。
  • 监控 argmax 率与 H 一起看：H 尚可但关键工具位已几乎确定性，仍可能探索不足。

思考题

1. 固定 logits，把 τ 从 1 降到 0.5，π 与 H(π) 如何变？

分布变尖，峰值动作概率上升，熵下降。极端 τ→0 时接近 one-hot，H→0。

2. 为什么说 ∇logπ 对 logits 是「减期望」？这对 baseline 意味着什么？

∂logπ(a)/∂φ = 1_a − π，在 π 下对 a 取期望为 0。因此只依赖 s 的 baseline 不会改变梯度期望，只影响方差——这是 REINFORCE+baseline 成立的基础。

3. PPO 的 entropy coef 与采样温度能否互相替代？

不能简单替代。c_ent 改变训练目标下的最优尖锐度；采样 τ 只改变当前如何从已有 π 取样。训练未见过的温度，推理硬拧，分布与梯度记账可能系统性偏离。

4. 熵正则与 KL(π∥π_ref) 各约束什么？

熵约束策略自身的不确定性（尖不尖）；KL 约束相对参考分布的偏离（漂不漂）。可以同时「高熵但离 ref 很远」或「低熵但贴着 ref」。见站内 KL 文。

5. 为什么大词表上「平均 token 熵很大」不一定代表探索健康？

均匀分布基线是 log|V|，绝对熵被词表撑大；且平均可能掩盖少数关键位置的塌缩。需要归一化或分层（位置 / 动作类型）指标。
