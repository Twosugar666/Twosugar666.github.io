学习笔记｜DPO：跳过奖励模型，直接用偏好对优化策略（Bradley-Terry / 隐式奖励）

2026-09-10 · 收藏夹：算法 / RL · 学习笔记
经典：Rafailov et al. · Direct Preference Optimization: Your Language Model is Secretly a Reward Model （NeurIPS 2023）· arXiv:2305.18290。 注意：DPO ≠ DAPO（后者见 2026-09-04 DAPO 笔记，是 GRPO 长 CoT 训练细节）。 交叉： PPO、 GRPO、 REINFORCE、 Importance Sampling。

背景与动机

经典 RLHF 管线大致三段：① SFT 得到 π_SFT；② 用人类偏好对训奖励模型（RM）；③ 以 RM 为奖励，用 PPO 等对策略做 RL，并用参考模型 π_ref 做 KL 约束防崩。 痛点叠在一起：训 RM 要数据与校准；PPO 要价值函数 / 优势估计与采样稳定性；在线 rollout 贵；超参多。

DPO（Direct Preference Optimization） 的核心洞察：在 Bradley-Terry 偏好模型下，KL 约束 RL 的最优策略对应一个隐式奖励，可写成策略与参考策略的 log 比。于是可以跳过显式 RM + PPO 环，直接在偏好对 (y_w, y_l) 上对 π_θ 做分类式损失。

一句话：DPO = 把「最优策略下的隐式奖励 r = β log(π_θ/π_ref) + const」代回 Bradley-Terry，得到只需偏好对的 −log σ(…) 目标；模型「秘密地」扮演奖励模型。

机制拆解

① RLHF 管线 vs DPO 捷径

阶段PPO-RLHFDPO
SFT需要通常需要（作初始化 / π_ref 来源）

② Bradley-Terry：偏好概率

# 人类（或裁判）偏好：在 prompt x 上 y_w ≻ y_l
P(y_w ≻ y_l | x) = σ( r(x, y_w) − r(x, y_l) )

# σ 为 logistic sigmoid
# r(x, y) 是标量奖励（未知，经典 RLHF 用神经网络估）

BT 模型只关心奖励差，不关心绝对尺度——这为后面「加常数不影响」留下空间，也解释了为何隐式奖励可以带 + const。

③ 最优策略下的隐式奖励

考虑带 KL 约束的目标：最大化 E[r] − β KL(π || π_ref)。最优策略满足（推导见原论文）： 

# 最优策略形式（示意）
π*(y|x) ∝ π_ref(y|x) · exp( r(x,y) / β )

# 反解「隐式奖励」（差一个仅依赖 x 的归一化项）
r(x, y) = β · log( π*(y|x) / π_ref(y|x) ) + β · log Z(x)
# 常写：
r(x, y) = β log( π_θ(y|x) / π_ref(y|x) ) + const(x)

关键：若把当前策略 π_θ 当作「最优策略族」中的成员，则策略比本身就编码了奖励。不必再维护一个独立 RM 网络——这就是副标题 “Your Language Model is Secretly a Reward Model” 的含义。

④ DPO loss

# 把隐式 r 代入 BT，const(x) 在差分中消去：
# P(y_w ≻ y_l | x) = σ(
#     β log(π_θ(y_w|x)/π_ref(y_w|x))
#   − β log(π_θ(y_l|x)/π_ref(y_l|x))
# )

# 最大似然 → DPO 损失（偏好对上）
L_DPO = − E_{(x,y_w,y_l)} [
  log σ(
      β log(π_θ(y_w|x)/π_ref(y_w|x))
    − β log(π_θ(y_l|x)/π_ref(y_l|x))
  )
]

# 实现时：对 y_w / y_l 的 token logprob 求和（注意 mask）；π_ref 冻结
符号作用
β温度 / KL 强度：β↑ 更贴 π_ref（保守）；β↓ 更敢偏离参考、拟合偏好更猛，也更易过拟合或崩语言质量
π_ref通常取 SFT 模型；提供隐式奖励的分母与正则锚点
y_w / y_l同一 x 上的胜出 / 落败回复；数据质量决定上限

⑤ 与 PPO-RLHF、GRPO / 可验证奖励栈

对照PPO-RLHFDPOGRPO / 规则奖励栈
监督信号 RM 标量奖励 偏好对（相对） 可验证规则 / 测试 / 判题（常绝对或组内相对）
是否在线采样 是（RL 环） 经典设定离线偏好 是（组采样 rollout）
与参考模型 显式 KL 项 进 log-ratio 可选；许多 RLVR 更弱依赖偏好 RM
典型场景 对齐、有害性、风格 同左，工程更简单的离线对齐 数学 / 代码 / agent 工具成功等可自动判

关系要分清：DPO 解决的是偏好数据上的对齐目标重参数化；GRPO 等解决的是可验证奖励下的相对策略梯度。不是互相替代：无可靠自动奖励时偏好/DPO 更自然；有 unit test / 终局对错时 RLVR 往往更直接。 再强调：DAPO 名字相近，但是给 GRPO 补 Clip-Higher / Dynamic Sampling 等训练细节的工作，不是 Direct Preference Optimization。

与 Importance Sampling / PPO clip 的联系：DPO loss 里出现的是 π_θ/π_ref 的 log 比，但是偏好分类目标，不是 PPO 里对采样策略的 importance-weighted 优势更新。读公式时不要把两套 ratio 语义混为一谈。

实践建议

  • π_ref 冻结且与初始化一致。 常见：π_θ 从 SFT 初始化，π_ref 同权重拷贝后冻结。训练中误更新 ref 会毁掉比的含义。
  • β 当正则旋钮扫。 过小易「偏好过拟合」与分布外胡话；过大则几乎不动，偏好学不动。
  • 偏好对质量 > 损失花样。 标签噪声、y_w/y_l 过近或过无可比，都会让 σ 梯度没意义。
  • 长度偏置要警惕。 人类偏好有时偏爱长回复；可做长度归一或数据过滤，避免策略只会注水。
  • 能规则判就优先规则。 数学/代码/agent 成功条件清晰时，GRPO 类栈往往比硬标偏好更可扩展；DPO 更适合主观对齐轴。
  • 命名消毒。 文档与实验名写全 Direct Preference Optimization，避免与 DAPO / 其他 *PO 混检索。
  • 评测分轴。 对齐榜（有害、拒绝、风格）与能力榜（GSM/代码）分开看；DPO 提升前者时可能伤后者，需同时回归。

思考题

  1. 为什么把隐式奖励代入 BT 后，只依赖 x 的 const / Z(x) 可以消掉？
    参考答案 BT 只看 r(x,y_w)−r(x,y_l)。若 r = β log(π/π_ref) + c(x)，则差分中 c(x) 相减为零；Z(x) 同样只依赖 x。因此偏好概率只剩下两条回复的 log-ratio 之差，得到 DPO 的 σ 参数。
  2. β 增大时，DPO 训练通常更「保守」还是更「激进」？为什么？
    参考答案 更保守。β 来自 KL 约束强度：越大表示越不愿意偏离 π_ref，隐式奖励尺度下同样的策略偏离对应更强的惩罚感；loss 里 β 放大 log-ratio 差，拟合偏好时也会被参考锚得更紧。过小则更敢改策略，风险是过拟合偏好与语言崩坏。
  3. DPO 相对 PPO-RLHF 省了什么，又可能缺什么？
    参考答案 省了显式 RM 训练与在线 PPO 环（价值估计、采样稳定性等）。可能缺：在线探索（经典 DPO 吃离线偏好，难主动发现分布外更好回复）；奖励可解释的独立 RM；以及与环境交互式任务的直接对接——那些更常走 RLVR/PPO。
  4. 为何说 DPO 里的 π_θ/π_ref 与 PPO 的 importance ratio 语义不同？
    参考答案 PPO/IS 的 ratio 用于修正「数据由旧策略采样」的 off-policy 偏差，并常与 advantage、clip 组成 surrogate。DPO 的比来自最优策略↔奖励的重参数化，进入的是偏好分类的 logistic 似然，不扮演「用旧策略样本估新策略目标」的 IS 权重角色。
  5. 什么时候该选 DPO，什么时候该选 GRPO/DAPO 一类？
    参考答案 有可靠人类/裁判偏好、目标偏对齐主观轴 → DPO（或同类偏好目标）合适。有可自动验证的对错/测试/工具成功 → GRPO 等 RLVR 更合适；DAPO 是该栈上的训练细节增强，不是偏好法。很多系统两轴都会用：先 SFT，再偏好对齐，再对可验证任务做 RL。
