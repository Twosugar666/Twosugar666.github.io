学习笔记｜RMSNorm：去掉 mean-centering、只留 re-scaling——从 BatchNorm / LayerNorm 的不变性、Post-LN 与 Pre-LN 的梯度尺度，到现代 LLM 为什么默认用它

2026-10-15 · 收藏夹：算法 / Infra · 学习笔记
经典来源：Biao Zhang、Rico Sennrich · Root Mean Square Layer Normalization（NeurIPS 2019） · arXiv:1910.07467； Jimmy Lei Ba、Jamie Ryan Kiros、Geoffrey Hinton · Layer Normalization · arXiv:1607.06450； Sergey Ioffe、Christian Szegedy · Batch Normalization · arXiv:1502.03167； Ruibin Xiong et al. · On Layer Normalization in the Transformer Architecture（ICML 2020） · arXiv:2002.04745。 结论与数字均引自原论文；「玩具实验」一节为本文用 numpy 自跑的示意，不代表任何真实模型或 GPU kernel 的性能。 交叉： Attention、 FlashAttention、 RoPE、 Adam / AdamW、 Muon、 MoE 路由。

背景与动机

打开任何一个 2023 年之后的开源 LLM 代码，Transformer block 的第一行几乎都是 h = x + Attn(RMSNorm(x))。这个看似最不起眼的算子，背后串着三件事：归一化在统计哪个维度（BatchNorm → LayerNorm）、归一化放在残差的哪一侧（Post-LN → Pre-LN）、以及归一化到底需要哪些统计量（LayerNorm → RMSNorm）。

Zhang & Sennrich 2019 的出发点很朴素：LayerNorm 在 RNN 上能显著加速收敛，但它本身很贵——论文报告 TensorFlow 版 RNNSearch 里加 LayerNorm 后比不加还慢约 67%。他们的假设是：LayerNorm 起作用的是 re-scaling 不变性，而不是 re-centering 不变性。如果假设成立，均值那一项可以整个拿掉。这篇笔记沿着这条线把三代归一化串起来，并讨论它在 LLM 训练与推理里的实际后果。

机制拆解

① BatchNorm 与 LayerNorm：统计的轴不同

# 记一层的 summed inputs 为 a = W·x ∈ Rⁿ（n 为隐藏维度），g / b 为可学习的逐维 gain / bias

# BatchNorm（Ioffe & Szegedy 2015）：沿 batch 维统计，每个特征一组 μ / σ
μ_i = mean_{batch}(a_i),   σ_i² = var_{batch}(a_i)
ā_i = g_i · (a_i − μ_i) / sqrt(σ_i² + ε) + b_i
# 训练用 batch 统计，推理用滑动平均 → 训推行为不同；依赖 batch 大小；对变长序列 / RNN 不友好

# LayerNorm（Ba et al. 2016）：沿特征维统计，每个样本（每个 token）一组 μ / σ
μ = (1/n) Σ_i a_i,   σ = sqrt( (1/n) Σ_i (a_i − μ)² )
ā_i = g_i · (a_i − μ) / σ + b_i
# 与 batch 无关；训练与推理完全一致；天然适合逐 token 计算

对语言模型来说，LayerNorm 的决定性优势是「每个 token 独立」：batch 里混着不同长度、不同 padding 的序列，KV cache 推理时 batch 每一步都在变，按 batch 统计根本无法定义稳定的行为。

② RMSNorm：只保留二阶矩

# Zhang & Sennrich 2019，式 (4)
RMS(a) = sqrt( (1/n) Σ_i a_i² )
ā_i    = a_i / RMS(a) · g_i                # 原论文的一般形式还可加 bias b，现代 LLM 基本不用

# 与 LayerNorm 的关系：当 μ = 0 时，σ = RMS(a)，两者完全相等
# 几何：输出被压到半径 √n 的球面上（再逐维乘 g）

# pRMSNorm：只用前 p% 的维度估计 RMS（论文用 p = 6.25%）
RMS_p(a) = sqrt( (1/k) Σ_{i≤k} a_i² ),   k = ⌈n·p⌉
  • 为什么要除以 √n（用 RMS 而不是 L2 范数）：论文实验里直接用 L2 范数归一化不起作用；作者的解释是球面半径随向量维度缩放，能让归一化在不同宽度的层之间保持一致的数值尺度。
  • 省了什么：LayerNorm 需要先算 μ、再算 (a − μ)² 的均值（或用 Welford 合并成一遍），反向也要对两个统计量求导；RMSNorm 前向只有一次 Σa² 归约，反向少一条均值分支。
  • pRMSNorm 的教训：理论上计算更少，但论文发现它有时反而更慢，原因是框架的张量切片实现不够好——「少算」不等于「更快」，访存模式更关键（这一点在 FlashAttention 里已经见过）。

③ 不变性：到底丢掉了什么（论文 Table 1）

与 LayerNorm 相比，RMSNorm 只少了一格：权重矩阵整体平移（给 W 每一行加同一个向量，等价于给 a 的每一维加同一个偏移）。来源是 RMS 的线性性 RMS(α·a) = α·RMS(a)：任何对 a 的整体缩放都被分子分母抵消，但平移不行。论文的实验结论是：去掉这一格对 BLEU / 收敛几乎没有影响——这就是「re-scaling 才是关键」的经验证据。

④ 梯度视角：Jacobian 把「径向」投影掉

# 忽略 ε 与 g，令 r = RMS(x)，y = x / r
∂y/∂x = (1/r) · ( I − x·xᵀ / (n·r²) )          # RMSNorm
∂y/∂x = (1/σ) · ( I − 1·1ᵀ/n − ŷ·ŷᵀ/n )          # LayerNorm，ŷ 为归一化后的输出

# 推论 1：(∂y/∂x)·x = 0 —— 沿 x 自身方向的扰动对输出无影响（scale invariance 的微分形式）
# 推论 2：回传到 x 的梯度 ∇_x L 与 x 正交
# 推论 3：若 W 位于 norm 之前，L(c·W) = L(W) ⇒ ∇_W L ⊥ W，
#        纯 SGD 下 ‖W‖ 只增不减（勾股定理），有效学习率 ∝ lr / ‖W‖²
# gain 的梯度：∂L/∂g = ∂L/∂v ⊙ (a / RMS(a))，与输入、权重的整体尺度无关（论文 §4.2）

推论 3 是一个常被忽略的联系：归一化层让上游权重的「范数」变成无关自由度，于是 weight decay 实际上在控制有效学习率，而不是在做传统意义的正则化（van Laarhoven 2017 的分析）。这正是站内 AdamW 解耦权重衰减、以及 Muon 讨论「更新 RMS 对齐」时背后的同一件事。

⑤ 放在哪里：Post-LN vs Pre-LN

# Post-LN（原始 Transformer）
x_{l+1} = Norm( x_l + F(x_l) )
# Pre-LN（GPT-2 之后的主流）
x_{l+1} = x_l + F( Norm(x_l) )          # 输出层前还需一个 final Norm

# Xiong et al. 2020，Theorem 1（初始化时，最后一个 FFN 的 W² 的梯度）
Post-LN :  ‖∂L/∂W²_L‖_F ≤ O( d · sqrt(ln d) )          # 与层数 L 无关
Pre-LN  :  ‖∂L/∂W²_L‖_F ≤ O( d · sqrt(ln d / L) )      # 随层数按 1/√L 缩小
# Lemma 2：Post-LN 中进入 LN 之前的隐状态 E‖x‖² 各层都保持 (3/2)d；
#          Pre-LN 满足 (1 + l/2)·d ≤ E‖x_l‖² ≤ (1 + 3l/2)·d，随深度线性增长

直观解释：Norm 会把梯度按输入尺度缩小（Lemma 3：LN 的 Jacobian 范数是 O(√d / ‖x‖)）。Post-LN 每层输入尺度固定，靠近输出的参数梯度很大，大学习率一上来就不稳，所以必须 warm-up；Pre-LN 的残差流随深度变长，梯度被自动按 √L 缩小，论文实验显示去掉 warm-up 也能训到可比结果、调参更少。一个常被讨论的代价是：残差流越来越长，深层子层的输出相对残差流的占比越来越小，深层的有效贡献可能被稀释，这是后来 DeepNorm（arXiv:2203.00555，带 α 放大残差的 Post-LN）、sandwich norm 等变体试图找回的东西。

# HF LlamaRMSNorm.forward（节选，注意精度路径）
input_dtype = hidden_states.dtype
hidden_states = hidden_states.to(torch.float32)                 # 统计量一律 fp32
variance = hidden_states.pow(2).mean(-1, keepdim=True)
hidden_states = hidden_states * torch.rsqrt(variance + self.variance_epsilon)
return self.weight * hidden_states.to(input_dtype)              # Llama：先 cast 再乘 gain
# Gemma：output * (1.0 + self.weight.float()) 之后再 .type_as(x) —— 先乘再 cast

Gemma 源码里专门写了一行注释对比两者的 cast 顺序。这个差别在 bf16 下会让同一份权重得到逐比特不同的输出——对推理无伤大雅，对 RL 的训推一致性则是需要注意的细节（见下文）。QK-Norm 与 RoPE 的顺序通常是先 norm、再旋转；与 MoE router z-loss 一样，它们都是在给 softmax 的输入尺度加约束（参见 Attention 里的温度讨论）。

和 LLM 训练 / RL / 推理的交叉

  • 训推不一致的来源之一。 训练框架与推理引擎的 RMSNorm 实现可能在归约顺序、是否 fp32 upcast、gain 乘法与 cast 的先后上不同，导致 token logprob 的细微差异。RL 里 π/µ 比率对这种差异敏感（站内 Importance Sampling、GPPO 都讨论过低概率 token 的比率噪声），对齐 norm kernel 是排查顺序里很靠前的一项。
  • 融合算子。 推理侧通常把「残差相加 + RMSNorm」融合成一个 kernel（如 vLLM 的 fused_add_rms_norm），省掉一次读写残差流；它是 memory-bound 算子，收益来自少一次 HBM 往返，而非少算几次乘法。
  • 量化友好性。 RMSNorm 的 gain 是逐通道缩放，可以被合并进下一层线性层的权重（SmoothQuant 一类方法常利用这一点做逐通道平衡）；没有 bias 也让这类合并更干净。
  • 激活尺度监控。 Pre-LN 残差流随深度增长，深层 RMSNorm 的输入可以很大；监控每层 norm 输入的 RMS、以及 gain 的分布，是发现训练异常（如个别通道激活爆涨）的低成本手段。

实践建议

  • 新模型默认 Pre-norm + RMSNorm，无 bias。 这是目前开源 LLM 的事实标准，省一次归约、少一组参数，效果与 LayerNorm 持平（Zhang & Sennrich 的 MT / 语言建模实验与后续大量模型的实践）。
  • 统计量一律 fp32。 Σx² 在 bf16 下误差很大；参照 HF 的写法先 upcast 再 rsqrt，ε 放在根号内（常见 1e-5 / 1e-6），并在训练与推理两侧保持同一 ε。
  • gain 不做 weight decay。 由推论 3，norm 之前的权重范数是「冗余自由度」；norm 自身的 gain 则直接决定输出尺度，衰减它会把各层输出向 0 拉，常见配置都会把 norm 参数排除在 decay 之外。
  • 深层 / 大学习率时加 QK-Norm。 它的成本是两次小 RMSNorm，换来 attention logit 的尺度上限；与 RoPE 组合时注意先 norm 后旋转。
  • 做 RL 时核对 norm 实现。 rollout 引擎与训练框架的 RMSNorm（cast 顺序、ε、是否融合残差）要逐项对齐；发现 π/µ 比率在 μ≈1 的 token 上也有系统偏差时，norm 和 RoPE 是最先该查的两个算子。
  • Post-LN 不是不能用，但要配套。 若出于表示能力考虑用 Post-LN 或 sandwich norm，必须配 warm-up 和更保守的初始化（DeepNorm 的 α / β 缩放是可参考的现成方案）。

思考题

1. 为什么 BatchNorm 不适合 LLM，而 LayerNorm / RMSNorm 适合？请从训练与推理两侧说明。

BatchNorm 沿 batch 统计，训练时依赖 batch 组成与大小，推理时改用滑动平均，训推行为不一致；变长序列与 padding 会污染统计量；自回归解码时 batch 每步都在变，甚至 batch=1，统计量无法稳定定义。LayerNorm / RMSNorm 对每个 token 独立统计，训练与推理计算完全相同，也与 KV cache、continuous batching 等推理机制兼容。

2. RMSNorm 相对 LayerNorm 只失去了「权重矩阵整体平移」不变性。请用 RMS 的线性性解释它为什么保留了缩放不变性，又为什么失去了平移不变性。

RMS(α·a) = α·RMS(a)，所以 a/RMS(a) 对 a 的任意正数整体缩放不变：权重矩阵整体缩放、输入整体缩放、单样本缩放都会在分子分母同时出现并抵消。平移 a → a + c·1 时，RMS(a + c·1) 不等于 RMS(a) 的任何简单函数，输出方向也随之改变（玩具实验里余弦相似度降到 0.45）；LayerNorm 先减均值，恰好把 c·1 消掉。

3. 若某层权重 W 位于 RMSNorm 之前，为什么纯 SGD 训练下 ‖W‖ 会单调增长？这和 weight decay 的作用有什么关系？

W 整体缩放不改变损失，即 L(c·W) = L(W)，对 c 求导得 ⟨∇_W L, W⟩ = 0，梯度与 W 正交。SGD 一步后 ‖W − η∇‖² = ‖W‖² + η²‖∇‖² ≥ ‖W‖²，范数只增不减。而梯度大小又与 ‖W‖ 成反比，有效学习率约为 η/‖W‖²，会随训练自然衰减。weight decay 把 ‖W‖ 拉回来，实际作用是维持有效学习率，而不是限制模型容量。

4. Xiong et al. 证明 Post-LN 最后一层梯度 O(d·√(ln d)) 与层数无关，Pre-LN 则按 1/√L 缩小。这为什么解释了「Post-LN 需要 warm-up」？

Norm 会把回传梯度按其输入尺度缩小。Post-LN 每一层的输入都被归一化到固定尺度，靠近输出的参数梯度在初始化时就很大，若一开始就用大学习率，更新步长过大导致训练不稳，warm-up 用小学习率熬过这段时期。Pre-LN 的残差流按 (1 + l/2)·d 量级随深度增长，final Norm 的输入尺度正比于 L，梯度自然被缩小到 1/√L，初始化附近梯度良态，因此可以去掉或缩短 warm-up。

5. （开放题）在 RL 后训练中，你会如何系统地排查「训练框架与推理引擎 logprob 不一致」里 RMSNorm 的贡献？

可讨论方向：(a) 固定一批输入，逐层 dump 两侧 norm 的输入与输出，计算最大绝对误差与相对误差，定位第一处显著分叉的层；(b) 分别对齐 ε、fp32 upcast、gain 乘法与 cast 顺序、是否与残差融合，观察 logprob 差异的变化；(c) 区分 norm 与其他算子（RoPE、attention kernel、matmul 的归约顺序）的贡献，可逐个把推理侧算子替换为训练侧参考实现；(d) 关注深层：Pre-LN 残差流尺度更大，同样的相对误差在深层对应更大的绝对误差；(e) 若无法完全对齐，配合 TIS / MIS 一类截断重要性采样修正，并监控比率分布的尾部。
