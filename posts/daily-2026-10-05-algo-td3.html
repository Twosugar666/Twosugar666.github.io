学习笔记｜TD3：双 Critic、延迟策略更新与目标策略平滑

2026-10-05 · 收藏夹：算法 / RL · 学习笔记
经典论文：Fujimoto, van Hoof, Meger · Addressing Function Approximation Error in Actor-Critic Methods · arXiv:1802.09477（ICML 2018）。 交叉： SAC、 Actor-Critic、 PPO、 Importance Sampling。

背景与动机

连续控制里，DDPG 用确定性策略 + 单个 Q 做 off-policy actor-critic，样本效率好看，但常因 Q 过估计 崩掉：策略去剥削 Q 面上的尖峰，目标跟着飘，训练像在追自己的影子。 TD3（Twin Delayed Deep Deterministic policy gradient）在 DDPG 骨架上加三招，专门压函数逼近误差的连锁反应——读完再看站内 SAC，能分清「双 Q 取 min」这条血脉是怎么从 TD3 流到最大熵设定的。

机制拆解：三招

招式做什么针对的病
Clipped Double Q两个 critic；Bellman 目标用 min(Q1′, Q2′)单 Q 过估计 → 策略剥削假高峰
Delayed policy updatescritic 多更新几次，再更新 actor / target（论文常用每 2 次 critic 更一次策略）策略一动目标就变，值函数来不及跟
Target policy smoothing算目标时给 target actor 的动作加截断高斯噪声策略钻 Q 的窄峰；平滑后更难「精确点名」误差点

① 目标怎么写

# 从 replay 采 (s, a, r, s', done)
noise = clip(N(0, σ), -c, c)          # 常用 σ=0.2·a_max, c=0.5·a_max
a' = clip( π_target(s') + noise, a_min, a_max )
y   = r + γ·(1-done)·min( Q1_target(s', a'), Q2_target(s', a') )

# 两个 critic 都回归同一个 y
L(θ_i) = E[ (Q_θi(s,a) - y)^2 ]  for i in {1,2}

# 策略（延迟触发）：只沿 Q1 做确定性策略梯度
∇_φ J ≈ E[ ∇_a Q_θ1(s,a)|_a=π_φ(s) · ∇_φ π_φ(s) ]
# 等价实现：minimize -Q_θ1(s, π_φ(s))

Target 网络用 Polyak 平均：θ′ ← τθ + (1-τ)θ′（常用 τ=0.005）。 注意：min 会偏保守（低估），换来的是少崩；这和 SAC 里 twin Q 取 min 是同一家族的工程选择。

② 和 DDPG / SAC / PPO 对照

DDPGTD3SACPPO
策略确定性确定性 + 探索噪声随机（最大熵）随机 on-policy
Critic单 Q双 Q + min双 Q + min + 软价值通常 V 或 GAE
更新节奏actor/critic 同频策略延迟可同频；温度另训多 epoch 小批量
探索动作噪声训练噪声 + target 平滑熵系数 α熵 bonus / 采样
典型场景连续控制原型更稳的确定性 off-policy连续控制默认强基线大规模 LLM RL 更常见

③ 实现时容易踩的坑

  • 只用一个 Q 做目标：等于退回 DDPG 过估计路径。
  • 策略每个 step 都更：丢掉 Delayed 的意义，目标抖动回来。
  • target 噪声过大或未 clip：动作被推到边界，平滑变成乱探索。
  • 把探索噪声和 target 平滑噪声混成一把：前者加在与环境交互的动作上，后者只进 Bellman 目标。
  • 和 SAC 光谱对不上还硬比 sample efficiency：TD3 无熵目标；需要随机策略或自动温度时优先 SAC。

实践建议

  • 连续控制离线复现：先 TD3 官方超参。 γ=0.99，τ=0.005，policy_freq=2，policy_noise=0.2，noise_clip=0.5（相对动作尺度，见 Fujimoto 开源与 Spinning Up）。
  • 监控 Q1−Q2 间隙与回报方差。 间隙长期拉大 → 过估计压力还在；策略回报突然尖峰后塌陷 → 常见剥削假 Q。
  • 需要随机策略 / 自动温度 → SAC；需要 on-policy 信任域 → PPO/TRPO。 TD3 不是万能替换。
  • 读 LLM RL 文献时的迁移点： 「双估计取保守」与「延迟更新降低目标抖动」在 token-level critic / value 头设计里仍常被借用；但动作空间与 replay 假设完全不同，不要直接搬超参。

思考题

1. 为什么目标要用 min(Q1′,Q2′) 而不是平均？

平均仍可能被偏高的那个拉高；min 显式偏向低估，专门对抗过估计驱动的策略崩坏。

2. Delayed update 和「更大的 Polyak τ」能互相替代吗？

不能干净替代。τ 控制 target 跟踪速度；delay 控制策略改变目标分布的频率。两者常一起用，机制不同。

3. Target policy smoothing 和探索噪声的区别？

探索噪声改变真实交互动作；smoothing 只在算 y 时扰动 target 动作，目的是正则化 Q，而不是直接探索环境。

4. TD3 的双 Q 与 SAC 的双 Q 差在哪？

形式都常取 min；SAC 还在软 Bellman / 策略目标里引入熵温度 α，最优策略是 Boltzmann 而非纯确定性贪婪。

5. 何时不该上 TD3？

离散大动作空间、必须 on-policy 约束、或目标本身是最大熵最优时；这些场景 PPO/GRPO 或 SAC 更贴。
