一线追踪｜RLVB：别只给最终答案发奖励——用模拟器精确后验给每一步打分，9/9 设置超过基座平均 +17.1%，证据充分才提交（51%/12%/74% vs 8%/0.4%/36%）

2026-11-26 · 收藏夹：RL / Agent · 一线追踪
主来源：Richmond Sin Jing Xuan、Peilin Feng（共同一作）、Wenbin Wang、Soujanya Poria（DeCLaRe Lab, Nanyang Technological University, Singapore）· Lazy Agents Answer Against Their Own Beliefs: Reinforcement Learning with Verifiable Beliefs Teaches Them to Act on What They Believe（arXiv:2611.32884，v1 2026-11-24；代码）。 所有论文数字均按原文 Tables 1–5、§4.5–4.6 抄录；「box 小实验」为本文在 box 上写的最小复现，明确不是论文数据。 交叉： GRPO、 DAPO、 FOCUS、 ReFold、 PersistGym-lite、 ARC。

背景与动机

RLVR 在数学、代码上很好用，因为有终局可验证答案。但长程 agent 的决策不止「答什么」，还有「什么时候答」。论文把证据不够就提交的行为叫 laziness：cups 任务里，掀开两个杯子后红柱仍可能在 2 号或 4 号杯下（各 1/2），agent 写出的 belief line 明明还是 Possible: cups 2, 4，动作却是 SUBMIT 4。终局奖励只看答案对错，一次蒙对和一次查实后答对拿同样的分，于是根本学不到「继续查」这件事。

  • 基础模型在证据不足、自己的 belief line 仍列多个答案的回合上，提交比例高达 3%–68%；HiddenGames 上 64%–97% 的答案出现在证据充分之前。
  • 加一个 belief line 不改训练也有用：Base (w/ belief) 在 9 个设置中的 8 个超过 Base，平均 +3.8%（Qwen3.5-4B 的 HiddenGames 上 +11.6%），但早提交率几乎没变。
  • 用 outcome reward 训练的 GRPO / PPO 平均反而低于基座：GRPO −1.0%、PPO −5.1%（Table 1 九列平均）。
  • 用 LLM judge 给每步打分也不稳：judge 看到隐藏答案后会奖励「蒙对的好运」、惩罚「正确但仍不确定的判断」，还要多训一个 critic、每步调一次 judge。

RLVB 的切入点是：训练沙盒本来就知道隐藏答案与观测规则，因此能算出每一步的精确后验；这个后验才是「证据支持的信念」，可以像 RLVR 验证最终答案一样被验证。于是 verifiable reward 从终点扩展到每一步——这就是标题里的 Verifiable Beliefs。

机制拆解

① 精确后验与「证据充分」的操作定义

每个任务有固定隐藏目标 θ、先验 p0、动作 at 与观测 ot∼p(·|θ,a1:t)。沙盒枚举 Θ，按式 (1) 算后验：

b_t(θ) ∝ p_0(θ) ∏_{s<t} p(o_s | θ, a_{1:s})          # 论文式 (1)

本论文的观测是确定性的 ⇒ b_t 就是 p_0 限制在与全部观测一致的 θ 上
B_t* = { y : b_t(y) > 0 }        # 证据仍允许的答案集合
"证据充分" 的操作定义：最高答案后验 ≥ 0.95（RoboQuest 无后验，用任务要求满足率代替）

这比让 LLM 自己写「我确定」要硬：0.5 就是 0.5，不能靠措辞蒙混。论文 §4.6 的分解分析全部建立在这个可回放的后验上。

② 后验教师：把「何时停」当成最优停止问题

式 (3) 用后验给答案与探索动作估值，再按式 (4) 得到教师策略 π*：

Q(b, y)   = log( c(t) · ρ̂(b) · b(y) / b_max )       c(t) = exp(−λ t / T)
Q^(n)(b,a) = Σ_o p(o | b, a) · V^(n−1)(b_{a,o})      V^(n)(b) = max_u Q^(n)(b,u)

p_ans   = σ( Δ / τ )          Δ = 最佳答案价值 − 最佳探索动作价值
π*(y|b) = p_ans · softmax_y Q(b,·)/τ
π*(a|b) = (1 − p_ans) · softmax_a Q^(n)(b,a)/τ

其中 ρ̂(b) 是 agent 自己答案的实测正确率（教师因此对 agent 的自适应），bmax=maxyb(y)，n 是前瞻深度。直觉很直接：如果现在答对概率最多 1/2，而再掀一个杯子就能确定，教师几乎把概率全给「掀杯子」。cups 示例里，掀杯子得约 0 分、提前答得约 −7.42 分（Figure 1），两类错误被非对称惩罚——多走一步只付一点时间折扣，早答付巨额负分。

③ 逐步奖励：只打分动作，不读 agent 写的信念

论文式 (5) 给出完整 turn 的奖励：

R(h, x) = log π*(u | b)  +  S_dec  +  η (S + W)
          └──── action ────┘   └──── stated belief 项（消融用）────┘

u       = 本回合动作（证据动作或提交答案）
S       = Σ_y b(y) log b_β(y)      # belief line 的对数得分，β 是 line 解析出的集合
W       = −m · |B \ B*| / |B|     # 惩罚 line 过宽
S_dec   = log π*(a_β | b)          # 按 line 当后验时教师会做的动作
主结果 RLVB 只用 action 项；RLVB (EM) 与消融才加 belief 项。

关键点常被误读：奖励从不读取 agent 写的 belief line，却因为更新提高整个 turn（推理 + line + 动作）的似然，line 被顺带训练。作者测出的结果是 agent 学会了「按自己写的 line 行动」，而不是「把 line 写得更准」——这正好是元认知里 monitoring 与 control 的区别，也是本文最值得记的一句话。

④ 更新：同一历史内比较多个 turn，而不是整条轨迹

Phase k 先固定 πk 采 episode；在每个历史 h 上采样 N 个 turn xi，用 R 打分，再做组内加权对数似然更新；当 πφ 与 πk 的 KL 超过 ε 就结束本 phase（每 phase 相当于一次策略镜像下降）。教师动作以 0.5 起始、逐 phase 衰减的概率介入，类似 DAgger；一半训练场景还会从随机证据动作开局，覆盖 agent 自己到不了的状态。 

轨迹级（GRPO）：Σ_e Σ_t A_e ∇ log π(x_{e,t} | h_{e,t})     # A_e 由整条 episode 的最终奖励给出
步级（RLVB）  ：Σ_h Σ_i w_i ∇ log π(x_i | h)              # w_i 只比较同一 h 下的 N 个 turn

RLVB    : w_i ∝ R(h,x_i) − (1/(N−1))Σ_{j≠i} R(h,x_j)      # 论文式 (10)，组内相对
RLVB-EM : w_i ∝ exp(R(h,x_i)/α)，在 h 内归一化            # 直接估计 q_k(x|h) ∝ π_k e^{R/α}
教师拒绝的动作（π*(u|b) < π*(u_best|b)/20）不给正权重。

因此它与 GRPO 用的是同一类组内相对 learner，差别只在「组」的单位：GRPO 组是整条轨迹的 G 个样本，RLVB 组是同一历史下的 N 个候选 turn。这也是作者做公平对照的关键：同 learner，换奖励，九列全部胜出。

为什么涨点：更多证据，而不是同证据下更聪明

论文把准确率按「回答时的证据水平 e」拆成两部分（式 11）：more evidence = 在不同证据档位上重新分配何时回答；same evidence = 同一档位下的回答准确率变化。这是很漂亮的归因实验，值得任何 agent 训练复盘照抄。

换句话说：RLVB 训出的是「说到做到的停止策略」，不是更强的读数或更强的探索。这也解释了作者为何强调后续方向是「让 posterior 可学习」「改善下一步选择」「证据充分时正确读观测」。与 FOCUS 的段级 critic 相比，RLVB 把 credit 细化到 turn，但依赖 simulator 的后验；与 ARC 的 rollout 控制相比，一个优化「生成哪些样本」，一个优化「何时停止采样」，可以叠加但要重做 reward 对齐。

局限与实践建议

  • 规则必须已知：后验可精确计算是整套方法的前提。开放任务要先学/估 posterior；动作空间大时 n 步前瞻要改浅层或采样。
  • line 的表达力有限：集合形式无法表达「60% 可能是 A」，只能列可能项；这会影响 monitoring 的上限。
  • 证据足够也会读错：训练后「有充分证据却答错」的比例从 2%–4% 升到 10%–15%（主要在 Tabletop），因为 agent 会按自己错的 line 行动。
  • 离教师仍远：Pro-Worlds 教师 100%，RLVB 最好 32.4%；作者的下一步是学 posterior、改善动作选择、训练观测读取。
  • 落地顺序建议：先确认环境能输出后验/充分性信号 → 用同 learner 做 outcome vs posterior reward 的 A/B（保持采样预算一致）→ 用式 (11) 拆 more/same evidence → 最后才考虑 harness 层的兜底检查。只加「拒绝首次回答」而不给 agent 证据反馈，在视觉任务上几乎无用。

思考题

1. 为什么说 outcome reward 「不能教 agent 何时提交」，即使正确答案可以被验证？

因为终局奖励把整条轨迹压成一个标量：一次证据不足的幸运猜测和一次查实后的正确回答赋值相同，而一次谨慎但最后失败的搜索被罚。停止决策依赖「当前证据是否已经锁定答案」，这是回合级信息，终局答案里没有。论文的实证是 GRPO / PPO (action-only) 在九列平均低于基座 1.0% / 5.1%，且 50 updates 后 18.8%–53.1% 的组全失败、组内优势为零。LLM judge 补的是「信念文本是否真实」，但 judge 看隐藏答案时会奖励蒙对、惩罚正确的不确定，仍不是证据充分性。

2. RLVB 的奖励从不读 belief line，为什么 line 的训练反而变了？这对 agent harness 设计意味着什么？

因为一个 turn 被定义为 x=(z, β, u)：推理、belief line、动作整体由 πφ(·|h) 生成，加权对数似然 L=−Σwi log πφ(xi|h) 会同时提高三者概率。奖励只看 u，但 β 与 u 的联合分布被一起拉近。结果是 agent 学会「line 说多个答案就继续、说单答案就提交」——control 跟随了 monitoring。对 harness 的启示：不要只把文本当解释性副产品；把 line 放进被更新的 turn，它就会变成策略的一部分，且不需要给它单独的 judge。

3. 式 (11) 的 more evidence / same evidence 分解为什么能区分「会停」与「会更准」？

把准确率写成 Σe f(e)a(e)，f 是在证据档 e 回答的局数占比、a 是该档的正确率。AccM−AccB 可恒等拆成 Σ(fM−fB)ā(e) + Σ(aM−aB)f̄(e)：第一项只改回答在证据档上的分布，第二项只在同档内改准确率。HiddenGames 的 +26.7 与 −8.5 说明 RLVB 几乎全靠「把回答挪到高证据档」，同档里甚至更差（观察读错）。这也提示评估 agent 训练时别只看总准确率，要记录回答时的证据直方图。

4. 既然 harness 检查「拒绝首次回答」对 HiddenGames / Pro-Worlds 几乎无效，为什么 RoboQuest 上又有效？

Table 36：HiddenGames / Pro-Worlds 上加检查，RLVB 变化 ≤2.8pp；RoboQuest 上 +1.9–7.7pp（Qwen3.5-4B 54.0→61.7）。差别在可观测性：前两个基准的「证据是否充分」取决于 agent 通过小窗口看到的观测，harness 没有这些观测，要求再查一次只能产生低信息量的动作（Tabletop 上 base 继续工作的比例 17%/2%/3%，后续步有用的比例很低）；RoboQuest 的充分性由任务要求是否满足决定，harness 能直接检查，再查一次能补上真实缺口。结论：harness 兜底只在「充分性外置可查」时有效，否则要把信号放进训练而不是推理时闸门。

5. RLVB 和 DAPO 的动态采样、FOCUS 的段级 critic 分别解决什么层面的问题？能否直接互换？

DAPO 动态采样（见此文）解决「整条轨迹全对/全错导致组内无梯度」，在 episode 层面过滤/补采；ARC（见此文）进一步在 rollout 调度层早停与续跑；FOCUS（见此文）把 compaction 边界当 step，做段级信用分配；RLVB 则在每一步用环境后验给 turn 打分，并把「停」本身作为被训练的动作。四者粒度不同、前提不同：RLVB 需要可算后验，FOCUS 需要续跑树，DAPO/ARC 需要可重采样。互换前要重定义 reward 与组，不能直接把 RLVB 的 wi 套到轨迹级组内。
