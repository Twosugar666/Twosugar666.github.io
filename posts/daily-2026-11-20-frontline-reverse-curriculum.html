一线追踪｜Depth Before Breadth：把长程 Agent RL 拆成「进入能力区」与「从能力区完成」——只用终局奖励的配对优势 + 反向到正向课程；Qwen2.5-1.5B/7B 在 ALFWorld 拿到 90.1%/96.1%、WebShop 80.2%/82.6%

2026-11-20 · 收藏夹：RL / Agent · 一线追踪
来源：Siyuan Du（南京大学）、Yuxin Liu（北京大学）、Meng Tang（University of Wales, Aberystwyth）、Haoran Li、Yechao Bai（南京大学）、Feiyang Pan、Jia He · Depth Before Breadth: Reverse-to-Forward Curriculum with Advantage Decomposition for LLM Agent（arXiv:2611.24697，cs.AI，v1 页眉日期 2026-11-18）。 数字均为论文自报；主表为多次 seed 的均值 ± 标准差（如 90.1±2.0），Closed-Source 与 CRPS 行为单点。「box 小验证」一节为本文用纯 Python 实现的配对优势玩具复算。 交叉： GRPO、 FOCUS、 VH-GPO、 GACA、 DAPO。

背景与动机

长程 LLM Agent 的 RL 训练卡在两件事上：奖励稀疏和信用分配。失败的 rollout 每一步都没有信号；成功的 rollout 也只有一个终局奖励，要摊到整条轨迹上。组相对方法（GRPO）用同题多条 rollout 的组内相对回报做优势，缓解了 value model 依赖，但把同一个轨迹级优势广播给轨迹里的每个动作——「哪一步真正把任务推向成功」仍然不可见。

反向课程（reverse curriculum）是常见的解法：把训练起点放在离目标很近的位置，再逐步往前推。对 LLM Agent 有一个更省事的参考锚定变体——沿一条成功参考轨迹把起点往回退。论文指出它留下两个结构性问题：

  • 起点越往后退，轨迹越长，同一个粗粒度终局反馈要摊到更长的序列上：早期真正有用的动作更难被单独识别。
  • 参考锚定 limiting exposure：起点只在参考轨迹上，见不到策略自己探索时遇到的 off-reference 状态（也就是分布偏移下最容易失败的地方）。

论文的关键观察（Figure 1）是：把训练起点往回退的同时，策略的能力区（capability region）也朝着原始起点扩张。在一条成功参考轨迹上，用 Pass@1 > 80% 定义"当前策略可靠完成任务的起点集合"，在 checkpoint 20 / 40 / 60 上这个集合 progressively 向原始起点长大；到 ckp60 时，新的边界大约到了"剩余 60% 步数"的位置。这意味着一个新引入的起点虽然离目标还远，但可能只差几步就能进入策略已经会解的区域。于是"长程任务"被拆成两个短得多的问题：

  1. 如何进入能力区（短程，从边界外一步或几步跨进去）；
  2. 如何从能力区内完成任务（较长，但前面的训练已经部分解决）。

机制拆解

① 能力区与近边界集：只用终局奖励的定义

记决策上下文 c_t = (o_{≤t}, a_{<t}, x)，p_π(c) 是策略从 c 出发完成任务的概率。给定可靠性阈值 η： 

能力区        C_η(π) = { c : p_π(c) ≥ η }
近边界集      N_{η,δ}(π) = { c : |p_π(c) − η| ≤ δ },  0 < δ < min(η, 1−η)

训练上下文从近边界集 N_{η,δ}(π) 里取——这些点离"会不会"的分界最近，最 informative。
关键：能力区是策略诱导的（policy-induced），不需要对上下文空间做任何几何假设。
Figure 1 实操里 η 对应 Pass@1 > 80% 的阈值。

这和本站之前几篇长程 Agent RL 的切入角度互补：FOCUS 在压缩边界上学主动 critic，VH-GPO 在 teacher 能恢复的最深状态接管，GACA 按关键度混合步级/轨迹级优势。这里不引入额外模型，只重新组织"从哪些状态采样"和"同一个终局奖励怎么拆成两个信号"。

② 配对优势（Paired Advantage）：前缀按端点分组，后缀在同端点内比较

从近边界的一个起点采样一组 n 条 rollout，每条切成前缀和后缀。前缀决定到达哪个端点上下文 c_ℓ，后缀决定从该端点能否完成任务。把前缀按端点去重（两个前缀落在同一类，当且仅当它们的 <action> 序列相同——注意只比对 action，不比对 <think>）。对每个端点 e 采 N_R ≥ 2 条后缀：

量公式直觉
端点完成率V̂(e) = (1/N_R) Σ_j R_{e,j}从 e 出发能完成的频率，用后缀实测
左优势（前缀）A^L(e) = V̂(e) − (1/n) Σ_{e′∈E} m(e′) V̂(e′)这个前缀把你送进了一个更好解还是更难解的状态？
右优势（后缀）A^R(e,j) = R_{e,j} − (1/(N_R−1)) Σ_{j′≠j} R_{e,j′}同一端点下，哪条续写真的完成了？leave-one-out，不用自己

注意基线里的 m(e′) 是落在端点 e′ 的前缀条数——基线是前缀加权的，等于整组后缀完成率的平均。两个优势都只从终局二元奖励算出来，不需要 value model、不需要额外 rollout，也不需要 trainer 之外的 verifier 信号（论文强调"using terminal rewards alone"）。

更新时前缀段和后缀段用各自的 PPO-style clip： 

J(θ) = E[ (1/n) Σ_k ( (1/ℓ) Σ_{t=0}^{ℓ-1} min[ρ_{t,k} A^L(e_k), clip(ρ_{t,k},1−ε,1+ε) A^L(e_k)]
                       + (1/(T_k−ℓ)) Σ_{t=ℓ}^{T_k-1} min[ρ_{t,k} A^R(e_k,j_k), clip(ρ_{t,k},1−ε,1+ε) A^R(e_k,j_k)] ) ]

ρ_{t,k} = π_θ(a_{t,k}|c_{t,k}) / π_θ_old(a_{t,k}|c_{t,k})
前缀 ℓ 步共享 A^L（激励"进入能力区"）；后缀 T_k−ℓ 步共享 A^R（激励"从这里完成"）。

③ 反向 → 正向两阶段课程

阶段起点从哪来解决什么
Reverse成功参考轨迹上，从近目标处沿轨迹深度逐步往回退建立并沿轨迹深度扩张能力区，直到原始起点对多数任务可靠可解
Forward从原始起点出发、由策略自己采的前缀所到达的状态（含 off-reference）把能力区拓宽到参考轨迹之外，用 on-policy 探索覆盖分布偏移的状态

两个阶段都复用同一套配对优势。Reverse 阶段负责"由近及远地建立会解的区域"，Forward 阶段负责"从会解的区域往外长出去"——这正是标题 Depth Before Breadth 的含义：先把纵深做扎实，再横向铺开。

⑦ box 小验证（纯 Python：配对优势 vs GRPO 广播）

用一个最小玩具验证"配对优势能区分前缀端点，而 GRPO 广播不能"。两个前缀从同一边界起点出发，一个落在 e1、一个落在 e2；两者后面都跟了一条成功后缀（终局奖励同为 1）。设端点完成率 V̂(e1)=1.0、V̂(e2)=0.5： 

V̂(e1)=1.00  V̂(e2)=0.50   m(e1)=1  m(e2)=1   n=2
prefix-weighted baseline = (1/2)·(1·1.00 + 1·0.50) = 0.75
A^L(e1) = +0.25        A^L(e2) = −0.25

两条前缀的终局奖励都 = 1（同一后缀成功）
GRPO broadcast on prefix actions = [0.0, 0.0]   ← 组内无方差，信号为 0

结论：终局奖励完全相同时，GRPO 对两条前缀一视同仁；
      配对优势用"前缀把你送进哪个端点"给出 +0.25 / −0.25 的相反信号。
注意：A^R 用 leave-one-out（分母 N_R−1），端点内后缀全对时 A^R 为 0，
      所以这个玩具里区分完全来自 A^L，符合论文"收益取决于中间奖励如何分配"的消融结论。

实践建议

  • 组相对不够时，先看"组内是否真的有方差"：如果同一批 rollout 终局奖励全一样（长程任务里非常常见），GRPO 的优势直接为 0。此时要么继续分组（按前缀端点、按能力区状态），要么做环境侧的课程设计。
  • 端点去重只比 action、不比 think：论文明确用 <action> 序列判定两个前缀是否落在同一端点。若把 think 也算进去，几乎不会撞到同一端点，配对就退化成逐条比较。
  • δ 与 η 决定"边界采样"的带宽：太窄采不到足够样本去估 V̂(e)，太宽又混进能力区深处/外面的点。可先把能力区画出来（Pass@1 曲线），再按论文思路在阈值附近取带。
  • Reverse 先、Forward 后，别反过来：Forward 依赖"已有能力区"作为落点分布，先在参考轨迹上把能力区立起来，再往 off-reference 状态扩张；直接 on-policy 探索在稀疏奖励下大概率全失败、没有可用信号。
  • 和 step-level 信用分配正交：本文拆的是"前缀 vs 后缀"，与 GACA 的关键度加权、FOCUS 的主动 critic 可以叠加；代价是 Rollout 组织更复杂，需要按端点做分组和去重。
  • 读数注意：主表为多次 seed 均值±标准差，但部分基线（CRPS、闭源模型）为单点；ALFWorld All 在 1.5B 上 Ours 的 Clean 子任务（84.2）并不如 GiGPO（94.8），是 All 更高靠其它五类拉起来的。

思考题

1. 为什么"前缀加权基线"要乘 m(e′)，而不是对所有端点做简单平均？如果端点数很多、每个端点只有一条前缀，会发生什么？

(1/n)Σ_{e′} m(e′)V̂(e′) 是全部 n 条前缀的期望完成率——因为每条前缀都按它实际落到的端点计数。简单平均 (1/|E|)ΣV̂(e′) 会让"只有一条前缀落在的稀有端点"和"很多前缀落在的常见端点"等权，基线上偏或下偏。当每个端点只有一条前缀时 m(e)≡1、|E|=n，两种写法相同，A^L(e)=V̂(e)−mean(V̂)；此时 V̂(e) 靠 N_R 条后缀估计，噪声由 N_R 决定，论文要求 N_R≥2、实验里每个端点采多条后缀来压方差。

2. A^R 用 leave-one-out（分母 N_R−1）而不是 GRPO 的 std 归一，有什么好处？如果某个端点的 N_R 条后缀全成功或全失败会怎样？

leave-one-out 用"其它后缀的平均"作基线，天然排除样本自身，避免了把当前样本算进基线造成的偏差；也不需要估计 std（二元奖励在小样本下 std 极不稳定，N_R=2 时 std 几乎无意义）。端点内全成功时 A^R=0（没有可区分的续写），全失败时也是 0——这正是稀疏奖励的死区，光靠 A^R 学不到东西，必须靠 A^L 从"哪些前缀能进入更好的端点"提供信号；这也是消融里 Rev PA / Fwd PA 都关键的原因。

3. Forward 阶段为什么能覆盖 off-reference 状态？它和"直接对原始起点做 on-policy 探索"有什么本质区别？

因为 Forward 的训练上下文不是原始起点本身，而是"从原始起点出发、由当前策略采出的前缀所到达的中间状态"——这些状态是策略真实会遇到的分布内状态，包含参考轨迹上没有的分支。直接对原始起点做 on-policy 探索时，稀疏终局奖励下整条轨迹大概率全失败，组内没有相对信号；Forward 把这些中间状态当作新的"起始点"，利用 Reverse 阶段建立的能力区——其中相当一部分状态离能力区边界很近，几条后缀就能测出 V̂(e)，从而产生有效梯度。简单说，Reverse 提供了"可学的落点"，Forward 才敢往分布外走。

4. 在 Qwen2.5-7B 上 Ours 的 ALFWorld Pick/Look/Clean/Heat 四项都是 100.0±0.0，但 Cool 只有 85.9±6.0、WebShop Succ. 82.6。这说明方法在什么类型的任务上可能仍有限制？

饱和的是 ALFWorld 里相对模板化的单步/少步操作（Pick/Look/Heat），说明"进入能力区 + 区内完成"的拆分在这类短决策链上足够；Cool 和 WebShop 这类需要更长序列、多步状态跟踪与文本理解的任务仍有失败。能力区方法的有效性依赖"存在明显的能力边界，且跨过边界只需少数几步"——当任务本身没有这种结构（长链、边界模糊、需要组合泛化）时，配对优势能提供的信号增益会下降，且 V̂(e) 的估计也更 noisy。

5. （开放题）如果能力区的阈值 η 由 0.8 改成 0.5，Reverse 阶段和 Forward 阶段各自会怎么变？这对"从哪个状态开始训练"有什么系统性影响？

η 降低意味着能力区变大、边界向"更难的状态"移动：Reverse 阶段按 Pass@1≥η 判定"已掌握"，会更早宣布某段轨迹可解，于是起点可能退得更快，但训练在更不可靠的状态上开始，V̂(e) 的估计方差更高。Forward 阶段的近边界集 N_{η,δ} 也随之移动，采样点更靠近策略的真实失败区——可能提供更大的学习空间，也可能因终局成功太少而信号稀疏。实践上 η 应与采样预算联动：高 η 保证 V̂(e) 估计可靠但边界推进慢，低 η 推进快但噪声大。论文用 80% 作为 Figure 1 的观测阈值，但是否作为训练超参、δ 如何取，正文给出了定义而未在摘要中固定——复现时需要在自己的环境里扫这两个值。
